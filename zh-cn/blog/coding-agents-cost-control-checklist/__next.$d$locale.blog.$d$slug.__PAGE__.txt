<h2 id="常见问题">常见问题</h2>
<h3 id="为什么-coding-agent-在-api-计费下很贵">为什么 coding agent 在 API 计费下很贵？</h3>
<p>反复送 repo 上下文、多步工具与重试，使每次完成变更的 token 远高于单次聊天。</p>
<h3 id="claude-code-可以跟正式服务共用-api-密钥吗">Claude Code 可以跟正式服务共用 API 密钥吗？</h3>
<p>不可以。应给 coding agent 独立项目、密钥、白名单与点数上限。</p>
<h3 id="如何为-coding-agent-设花费上限">如何为 coding agent 设花费上限？</h3>
<p>固定项目点数天花板、耗尽前告警、白名单限制 frontier，并在 agent 设定 max steps / max tokens。</p>
<h3 id="应追踪哪些指标">应追踪哪些指标？</h3>
<p>每次成功任务的点数、每任务请求数、输入输出 token、依模型排序的花费。</p>
<h3 id="如何经企业闸道跑-claude-code">如何经企业闸道跑 Claude Code？</h3>
<p>把 base URL 指到闸道、项目密钥作 auth、清掉冲突的原厂环境变数，且只启用该项目允许的模型。</p>
