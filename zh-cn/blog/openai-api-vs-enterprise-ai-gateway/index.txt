<h2 id="简短回答">简短回答</h2>
<p>只有一个团队、只用 OpenAI 模型，而且 OpenAI 的项目上限已经满足你的预算规则，就直接用 OpenAI API。</p>
<p>出现下列任一情况，就该加一层 OpenAI 兼容网关：</p>
<ul>
<li>第二家供应商进来了，例如写代码用 Claude、大批量分类用 Gemini Flash，而财务希望只有一张账单、一套上限。</li>
<li>多个团队共用一笔 AI 预算，每个团队都需要跨供应商的上限和模型清单。</li>
<li>想用自己的提示词对比模型，又不想接入三套 SDK。</li>
</ul>
<h2 id="openai-平台已经提供的管控">OpenAI 平台已经提供的管控</h2>
<p>单一供应商时，过去需要网关才能实现的管控，OpenAI 大多已经自己做了：</p>
<ul>
<li>项目可以把测试和生产环境分开，各自有密钥、速率上限和消费上限（<a href="https://developers.openai.com/api/docs/guides/production-best-practices" target="_blank" rel="noopener noreferrer">生产环境最佳实践</a>）。</li>
<li>两种消费管控：消费提醒只发通知，流量照常；硬性消费上限会让受影响的请求返回 429（<a href="https://developers.openai.com/api/docs/guides/rate-limits" target="_blank" rel="noopener noreferrer">速率限制说明</a>）。</li>
<li>项目级的“Model usage”设置，限制项目可以调用哪些模型（<a href="https://help.openai.com/en/articles/9186755-managing-projects-in-the-api-platform" target="_blank" rel="noopener noreferrer">管理项目</a>）。</li>
<li>使用量等级（usage tier）会在累计付款达到一定金额前限制每月消费，从 Tier 1 每月 100 美元到 Tier 5 每月 200,000 美元。</li>
</ul>
<p>如果流量全部是 OpenAI，先把这些功能用好。</p>
<h2 id="直接接入的局限">直接接入的局限</h2>
<p>上面这些上限只覆盖 OpenAI 的模型。团队一接入 Claude，Anthropic 控制台就有另一套工作区、消费上限和密钥（<a href="https://platform.claude.com/docs/en/manage-claude/workspaces" target="_blank" rel="noopener noreferrer">Anthropic 工作区</a>）。再加上 Gemini，就是第三个控制台。实际情况会变成：</p>
<ul>
<li>有人离职时，要在三个地方签发和吊销密钥。</li>
<li>三套互相看不到的预算，“客服机器人每月跨所有供应商最多花 3,000 美元”这条规则没有地方能执行。</li>
<li>月底收到三张格式不同的账单。</li>
<li>代码分散在 OpenAI、Anthropic、Google 三套 SDK 里。</li>
</ul>
<p>网关在它们前面放一套密钥、上限和日志。</p>
<h2 id="代码要改哪里">代码要改哪里</h2>
<p>用 ATP Token 时 OpenAI SDK 照常使用，只改三个值（<a href="/zh-cn/docs/sdk-openai/">OpenAI SDK 说明</a>、<a href="/zh-cn/docs/cb-migrate-openai/">从 OpenAI 迁移</a>）：</p>
<pre><code>from openai import OpenAI

# 原来：client = OpenAI(api_key=&quot;sk-...&quot;)
client = OpenAI(base_url=&quot;https://api.atptoken.ai/v1&quot;, api_key=&quot;atp-...&quot;)

for model in [&quot;gpt-5.4&quot;, &quot;claude-sonnet-4-6&quot;, &quot;gemini-3-5-flash&quot;]:
    r = client.chat.completions.create(
        model=model,
        messages=[{&quot;role&quot;: &quot;user&quot;, &quot;content&quot;: &quot;请给这张工单分类：“退款十天还没到账”&quot;}],
        max_tokens=200,
    )
    print(model, r.choices[0].message.content, r.usage.total_tokens)
</code></pre>
<p>不变的部分：Chat Completions 的请求内容、响应内容、<code>stream=True</code> 的流式输出（<a href="/zh-cn/docs/sse-openai/">OpenAI SSE</a>），以及工具定义。</p>
<p>会变的部分：</p>
<ul>
<li>模型 id 以 <code>GET /v1/models</code> 返回的为准（<a href="/zh-cn/docs/models/">模型查询</a>）。OpenAI 模型沿用 <code>gpt-5.4</code> 这类熟悉的名称；其他模型用 <code>claude-sonnet-4-6</code>、<code>deepseek-v4-flash</code> 这类 id。</li>
<li>不在项目允许清单上的模型，会在发往任何供应商之前返回 403。</li>
<li>项目<a class="doc-term" href="/zh-cn/docs/credits/" data-def="计费单位。1 点＝USD 0.01；用量依各模型牌价换算成点数扣抵。">点数</a>用完时，请求返回 402（<a href="/zh-cn/docs/errors/">错误</a>）。</li>
<li>ATP 的 OpenAI 格式端点是 <code>/v1/chat/completions</code>、<code>/v1/models</code> 和 <code>/v1/files</code>。代码如果调用其他 OpenAI 端点，迁移前先查 <a href="/zh-cn/docs/chat/">API 参考</a>。</li>
</ul>
<p>使用 Anthropic 或 Google GenAI SDK 的团队不必改成 OpenAI 格式：同一个项目密钥也能在 <code>https://api.atptoken.ai</code> 配合这两套 SDK 使用（<a href="/zh-cn/docs/sdk-anthropic/">Anthropic SDK</a>、<a href="/zh-cn/docs/sdk-google/">Google GenAI SDK</a>）。</p>
