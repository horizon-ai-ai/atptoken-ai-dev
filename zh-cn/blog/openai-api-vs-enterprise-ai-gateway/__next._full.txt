<h2 id="何时直连够用">何时直连够用</h2>
<p>一产品、一供应商、少数密钥、财务暂可接受原厂后台。</p>
<h2 id="何时控制层划算">何时控制层划算</h2>
<p>第二供应商或模态、coding agent 与正式共用预算、财务要问哪个团队、资安要撤销与白名单预设。</p>
<h2 id="迁移形状">迁移形状</h2>

<h2 id="常见问题">常见问题</h2>
<h3 id="openai-api-与-ai-闸道有何不同">OpenAI API 与 AI 闸道有何不同？</h3>
<p>OpenAI API 是模型供应商界面。企业 AI 闸道位于客户端与一家或多家供应商之间，负责密钥、模型授权、路由、计量与纪录。</p>
<h3 id="公司何时不该再只直连-openai">公司何时不该再只直连 OpenAI？</h3>
<p>当多团队共用花费、导入第二家供应商、财务要项目归属，或资安要集中撤销与白名单时。</p>
<h3 id="ai-闸道会取代-openai-吗">AI 闸道会取代 OpenAI 吗？</h3>
<p>不会。闸道不取代模型品质或训练，而是增加治理与账务整合。</p>
<h3 id="从-openai-迁到相容闸道有多难">从 OpenAI 迁到相容闸道有多难？</h3>
<p>通常改 base URL 与 API 密钥；模型 id 需对齐目录与白名单。</p>
<h3 id="能否在同一企业闸道使用-anthropic-与-gemini">能否在同一企业闸道使用 Anthropic 与 Gemini？</h3>
<p>支援多格式的闸道可以，并以项目密钥约束。</p>
