<h2 id="openrouter-怎么收费-截至-2026-年-10-月">OpenRouter 怎么收费（截至 2026 年 10 月）</h2>
<p>OpenRouter 不在 token 价格上加价，官方说法是按供应商价格转付，费用在购买点数时收取（<a href="https://openrouter.ai/docs/faq" target="_blank" rel="noopener noreferrer">FAQ</a>）：</p>
<ul>
<li>Standard（按量付费）：银行卡 5.5%，最低 0.80 美元；加密货币 5%。</li>
<li>Business：8%。Enterprise：另议。</li>
<li>自带供应商密钥（BYOK）：Standard 和 Business 每月前 25,000 美元标价用量免费，超出部分收 5%。</li>
</ul>
<p>举两个例子。在 Standard 用银行卡买 1,000 美元点数，实付 1,055 美元。买 10 美元则实付 10.80 美元，因为最低 0.80 美元高于 5.5%。</p>
<p>财务需要留意两条条款：OpenRouter 保留在购买一年后让未使用点数失效的权利；未使用点数的退款必须在 24 小时内申请。开具发票（invoicing）只列在 Enterprise 方案里。</p>
<h2 id="openrouter-已经能为团队做的事">OpenRouter 已经能为团队做的事</h2>
<p>有些对比文章（包括本文旧版）把 OpenRouter 描述成没有团队管控的开发者钱包，这已经过时了。</p>
<ul>
<li>组织共用一个点数池，只有管理员能购买点数、修改账务、供应商和隐私设置。</li>
<li><a href="https://openrouter.ai/docs/guides/features/workspaces" target="_blank" rel="noopener noreferrer">工作区</a>可以把 API 密钥、路由默认值、guardrails 和监控分开，例如分成测试和生产环境。</li>
<li><a href="https://openrouter.ai/docs/guides/features/guardrails" target="_blank" rel="noopener noreferrer">Guardrails</a> 可以挂在成员或密钥上，组合按天、周、月重置的美元预算、模型白名单、供应商白名单、零数据保留规则，以及提示注入或个人信息过滤。多条同时生效时，以最严格的为准。</li>
<li>每个 API 密钥都能设置自己的点数上限，所有方案都支持。</li>
<li>所有方案都有活动日志和导出，可以按模型、密钥或成员分组。</li>
<li>Claude Code 可以接入 OpenRouter 的 Anthropic 兼容端点（<a href="https://openrouter.ai/docs/guides/guides/claude-code-integration" target="_blank" rel="noopener noreferrer">配置说明</a>）。</li>
</ul>
<p>如果这些管控已经够用，手续费也能接受，继续用 OpenRouter 是合理的。</p>
<h2 id="团队为什么找替代方案">团队为什么找替代方案</h2>
<p>常见原因，每一条都对应文档里查得到的差异：</p>
<ol>
<li>网关必须部署在公司网络内，或者流量只能发往公司自己持有的供应商账号。</li>
<li>财务希望预算绑定到产品线或成本中心。OpenRouter 在 Enterprise 以下，预算挂在成员和密钥上；工作区预算需要 Enterprise。</li>
<li>财务希望使用不会过期的预付点数，提前拨给每个项目。</li>
<li>部分应用用的是 Google GenAI SDK，团队希望网关直接支持这个格式，不必改写。</li>
</ol>
<p>下面每个替代方案分别回应其中几项。</p>
<h2 id="逐个看替代方案">逐个看替代方案</h2>
<h3 id="litellm-自建-proxy">LiteLLM：自建 proxy</h3>
<ul>
<li>适合：网关必须放在自己的云或 VPC 里，并且已经有供应商账号的团队。</li>
<li>费用：开源 proxy免费；你直接支付供应商账单，加上运维成本。部分功能（例如用户和密钥级别的“按模型”预算）需要 Enterprise 许可。</li>
<li>管控：可以按密钥、用户、团队和客户设置预算，重置周期如 <code>30d</code>；模型权限用 access group 管理。</li>
<li>需要注意：可用性、数据库、升级和安全审查都由你负责。Anthropic 的 Claude Code 文档提到有企业用 LiteLLM 按密钥追踪消费，同时注明它与 Anthropic 无关、未经其审计（<a href="https://code.claude.com/docs/en/costs" target="_blank" rel="noopener noreferrer">来源</a>）。</li>
</ul>
<h3 id="vercel-ai-gateway-托管-按供应商标价">Vercel AI Gateway：托管，按供应商标价</h3>
<ul>
<li>适合：已经部署在 Vercel 的团队，或想要托管网关、又不想在 token 上付平台费的人。</li>
<li>费用：token 不加价、不收平台费；可能有支付手续费；Enterprise 可开发票（<a href="https://vercel.com/docs/ai-gateway/pricing" target="_blank" rel="noopener noreferrer">定价</a>）。</li>
<li>管控：可以对团队、项目、API 密钥或成员设置预算，按天、周、月或不重置；超出后返回 HTTP 402；在 50%、75%、100% 发邮件提醒。</li>
<li>需要注意：Vercel 自己说明预算是软上限，越过上限的那一笔请求仍会完成。使用自带供应商密钥的消费不计入预算。团队级供应商白名单每 1,000 次请求收 0.10 美元。</li>
</ul>
<h3 id="atp-token-项目预付额度-每个项目自己的模型白名单">ATP Token：项目预付额度＋每个项目自己的模型白名单</h3>
<ul>
<li>适合：多个团队共用一笔 AI 预算，财务希望每个项目先拨款、并且只能调用审核过的模型。</li>
<li>费用：按输入和输出 token、以各模型标价计量，从点数中扣减。1 点 = 0.01 美元，充值 5 美元起，按量付费的点数不会过期（<a href="/zh-cn/docs/credits/" class="doc-term-def" data-def="计费单位。1 美元 = 100 点；用量依各模型牌价换算成点数扣抵。">点数</a>、<a href="/zh-cn/docs/topup/" class="doc-term-def" data-def="为钱包加值点数，最低 5 美元，用多少付多少。">充值</a>、<a href="/zh-cn/pricing/">定价</a>）。</li>
<li>管控：点数从组织往下拨到工作区、再到项目，项目只能花被拨到的额度，用完返回 402。每个项目有允许的模型清单，调用清单外的模型会在发往供应商之前返回 403（<a href="/zh-cn/docs/how-it-works/">运作方式</a>）。</li>
<li>格式：OpenAI、Anthropic、Google GenAI 官方 SDK 都能直接使用，只需更换 base URL 和密钥（<a href="/zh-cn/docs/sdk-openai/">OpenAI SDK</a>、<a href="/zh-cn/docs/sdk-google/">Google GenAI SDK</a>）。</li>
<li>需要注意：模型目录比 OpenRouter 小（11 家供应商、70+ 个模型，对比 500+）。点数不可退款。请求日志保留 7 天，月度复盘需要的数据请提前导出。</li>
</ul>
<p>Portkey 和 Helicone 也常出现在“OpenRouter 替代方案”清单里，放在 <a href="/zh-cn/blog/ai-gateway-comparison-2026/">LLM 网关对比</a>中一起讨论。</p>

<h2 id="把-openrouter-集成迁到-atp-token">把 OpenRouter 集成迁到 ATP Token</h2>
<p>如果你的代码用 OpenAI SDK 调用 OpenRouter，迁移只需更换 base URL、密钥和模型 id。</p>
<ol>
<li>在控制台创建项目，勾选允许的模型，例如 <a href="/zh-cn/models/claude-sonnet-4-6/">claude-sonnet-4-6</a> 和 <a href="/zh-cn/models/deepseek-v4-flash/">deepseek-v4-flash</a>（<a href="/zh-cn/docs/resources/" class="doc-term-def" data-def="这个 project 可以呼叫的模型清单；不在清单上的一律回 403。">工作区与项目</a>）。</li>
<li>给项目拨点数，这个金额就是它的上限（<a href="/zh-cn/docs/cb-budget-caps/">预算上限配置</a>）。</li>
<li>为项目创建密钥，以 <code>atp-</code> 开头，只显示一次（<a href="/zh-cn/docs/console-keys/" class="doc-term-def" data-def="以 atp- 开头的金钥，继承所属 project 的允许模型清单与点数余额。">管理密钥</a>）。</li>
<li>修改 client 和模型 id。OpenRouter 的 id 带供应商前缀（<code>vendor/model</code>）；ATP 的 id 以 <code>GET /v1/models</code> 返回的为准。</li>
</ol>
<pre><code>from openai import OpenAI

# 原来：OpenAI(base_url=&quot;https://openrouter.ai/api/v1&quot;, api_key=&quot;sk-or-...&quot;)
client = OpenAI(base_url=&quot;https://api.atptoken.ai/v1&quot;, api_key=&quot;atp-...&quot;)

r = client.chat.completions.create(
    model=&quot;claude-sonnet-4-6&quot;,
    messages=[{&quot;role&quot;: &quot;user&quot;, &quot;content&quot;: &quot;用两行总结这张工单。&quot;}],
)
print(r.choices[0].message.content)
</code></pre>
<ol start="5">
<li>发一个测试请求，确认它出现在请求日志里，并带有输入和输出 token（<a href="/zh-cn/docs/monitoring/">用量与日志</a>）。</li>
</ol>
<p>Claude Code 也是同样的做法，设置四个环境变量即可（<a href="/zh-cn/docs/cb-claude-code/">在 ATP 上运行 Claude Code</a>）。</p>
