# 充值与钱包

> Source: https://atptoken.ai/zh-cn/docs/topup/

你的按量付费（PAYG）钱包通过 Billing 页的 Stripe 充值。最低充值为 **USD 5**，且每个级距一律以 100 credits 兑 1 美元换算：

| 方案 | 价格 | Credits |
|---|---|---|
| Starter | USD 5 | 500 |
| Standard | USD 50 | 5,000 |
| Pro | USD 200 | 20,000 |
| Scale | USD 1,000 | 100,000 |

每次充值都会记入 Billing 历史（日期、金额、加入的 credits、充值后余额、状态）。**充值与 credits 不可退款。** Credits 以单一 Wallet 余额呈现。企业账号另可持有承诺的 **contract credits**（带到期日）；这些会计入该余额，并列在 Billing 页上。

> **Personal 与 Team organization 的区别**
>
> 充值是充进你的 **个人帐户**。在 **personal organization** 中，这份余额就是你的 key 直接花费的来源。若是 **team organization**，要先把 credits 分配给它（Console → Resources）— team org 里的 key 花的是 org 被分配到的 credits，不是个人钱包。
