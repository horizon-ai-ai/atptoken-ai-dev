<h2 data-md="h2" id="连接-gateway" class="group">连接 Gateway<a href="#连接-gateway" aria-label="此段链接" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<h3 data-md="h3" id="我需要特别的-sdk-吗" class="group">我需要特别的 SDK 吗？<a href="#我需要特别的-sdk-吗" aria-label="此段链接" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>不用。Gateway 相容 OpenAI、Anthropic 与 Google GenAI SDK——把它们指向 Gateway base URL 并用<a class="doc-term" href="/zh-cn/docs/resources/" data-def="权限与帐务的最小单位；密钥、允许模型、点数预算都挂在 项目 上。">项目</a>（project） <a class="doc-term" href="/zh-cn/docs/console-keys/" data-def="以 atp- 开头的密钥，继承所属 项目 的允许模型清单与点数余额。">API 密钥</a>即可。见 <a href="/zh-cn/docs/agents/">Integrations</a>。</p>
<h3 data-md="h3" id="base-url-是什么" class="group">base URL 是什么？<a href="#base-url-是什么" aria-label="此段链接" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>Anthropic 与 Gemini 格式用 <code>https://api.atptoken.ai</code>,OpenAI 格式用 <code>https://api.atptoken.ai/v1</code>。各 SDK 页会列出确切值。</p>
<h3 data-md="h3" id="可以串流回应吗" class="group">可以串流回应吗？<a href="#可以串流回应吗" aria-label="此段链接" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>可以。设 <code>stream: true</code>,Gateway 会以对应你 SDK 的格式串流 SSE。见 <a href="/zh-cn/docs/sse-openai/">OpenAI SSE</a> 与 <a href="/zh-cn/docs/sse-anthropic/">Anthropic SSE</a>。</p>
<h2 data-md="h2" id="模型与可用性" class="group">模型与可用性<a href="#模型与可用性" aria-label="此段链接" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<h3 data-md="h3" id="我的密钥能呼叫哪些模型" class="group">我的密钥能呼叫哪些模型？<a href="#我的密钥能呼叫哪些模型" aria-label="此段链接" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>只有它所属项目的 allowed list 上的模型。<a href="/zh-cn/docs/models/">GET /v1/models</a> 列出平台提供的清单；存取权在 request time 依项目强制检查——所以清单是选单，不是密钥的权限。</p>
<h3 data-md="h3" id="某个供应商挂掉会怎样" class="group">某个供应商挂掉会怎样？<a href="#某个供应商挂掉会怎样" aria-label="此段链接" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>每个模型由一个供应商池 服务，Gateway 会自动切换。若某模型的所有供应商都不可用，你会收到带 <code>Retry-After</code> 的 <code>503</code>。见 <a href="/zh-cn/docs/provider-routing/">供应商路由与备援</a>。</p>
<h3 data-md="h3" id="为什么-reasoning-模型回传-200-但内容是空的" class="group">为什么 reasoning 模型回传 200 但内容是空的？<a href="#为什么-reasoning-模型回传-200-但内容是空的" aria-label="此段链接" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p><code>max_tokens</code> 设太低了。推理模型（extended thinking）的思考会吃同一个额度；额度在产生可见输出前就用完，你会拿到空的 <code>200</code>——通常用量为零、也不会扣<a class="doc-term" href="/zh-cn/docs/credits/" data-def="计费单位。1 点＝USD 0.01；用量依各模型牌价换算成点数扣抵。">点数</a>。把 <code>max_tokens</code> 调高到「思考+预期输出」都够用。见<a href="/zh-cn/docs/errors/">常见回应</a>。</p>
<h3 data-md="h3" id="atp-token-只有文字模型吗" class="group">ATP Token 只有文字模型吗？<a href="#atp-token-只有文字模型吗" aria-label="此段链接" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>不是。目录还包含图像、影片、语音(TTS)与 embedding 模型。各模态的用途与计费方式见<a href="/zh-cn/docs/media/">媒体模型</a>。</p>
<h2 data-md="h2" id="计费与用量" class="group">计费与用量<a href="#计费与用量" aria-label="此段链接" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<h3 data-md="h3" id="怎么计费-点数可以退款吗" class="group">怎么计费？点数可以退款吗？<a href="#怎么计费-点数可以退款吗" aria-label="此段链接" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>用量以 input + output tokens 计量，并以点数支付(1 点数 = USD 0.01)。<a class="doc-term" href="/zh-cn/docs/topup/" data-def="为钱包加值点数，USD 5 起充值，用多少付多少。">充值</a>与点数皆不可退款。见 <a href="/zh-cn/docs/credits/">点数如何运作</a> 与 <a href="/zh-cn/docs/topup/">充值与钱包</a>。</p>
<h3 data-md="h3" id="我怎么看花了多少" class="group">我怎么看花了多少？<a href="#我怎么看花了多少" aria-label="此段链接" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
