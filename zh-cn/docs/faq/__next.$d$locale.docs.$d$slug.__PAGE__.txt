<p>不用。Gateway 相容 OpenAI、Anthropic 与 Google GenAI SDK — 把它们指向 Gateway base URL 并用 <a class="doc-term" href="/zh-cn/docs/console-keys" data-def="以 atp- 开头的金钥，继承所属 project 的允许模型清单与点数余额。">project API key</a> 即可。见 <a href="/zh-cn/docs/agents">Integrations</a>。</p>
<h3 id="base-url-是什么">base URL 是什么？</h3>
<p>Anthropic 与 Gemini 格式用 <code>https://api.atptoken.ai</code>,OpenAI 格式用 <code>https://api.atptoken.ai/v1</code>。各 SDK 页会列出确切值。</p>
<h3 id="我的-key-能呼叫哪些模型">我的 key 能呼叫哪些模型？</h3>
<p>只有它所属 <a class="doc-term" href="/zh-cn/docs/resources" data-def="权限与帐务的最小单位；金钥、允许模型、点数预算都挂在 project 上。">project</a> 的 allowed list 上的模型。<a href="/zh-cn/docs/models">GET /v1/models</a> 列出平台提供的清单；存取权在 request time 依 project 强制检查 — 所以清单是选单，不是 key 的权限。</p>
<h3 id="可以串流回应吗">可以串流回应吗？</h3>
<p>可以。设 <code>stream: true</code>,Gateway 会以对应你 SDK 的格式串流 SSE。见 <a href="/zh-cn/docs/sse-openai">OpenAI SSE</a> 与 <a href="/zh-cn/docs/sse-anthropic">Anthropic SSE</a>。</p>
<h3 id="某个-provider-挂掉会怎样">某个 provider 挂掉会怎样？</h3>
<p>每个模型由一个 provider pool 服务，Gateway 会自动 fail over。若某模型的所有 provider 都不可用，你会收到带 <code>Retry-After</code> 的 <code>503</code>。见 <a href="/zh-cn/docs/provider-routing">Provider routing</a>。</p>
<h3 id="怎么计费-credits-可以退款吗">怎么计费？credits 可以退款吗？</h3>
<p>用量以 input + output tokens 计量，并以 <a class="doc-term" href="/zh-cn/docs/credits" data-def="计费单位。1 美元 = 100 点；用量依各模型牌价换算成点数扣抵。">credits</a> 支付(1 credit = USD 0.01)。<a class="doc-term" href="/zh-cn/docs/topup" data-def="为钱包加值点数，最低 5 美元，用多少付多少。">充值</a>与 credits 皆不可退款。见 <a href="/zh-cn/docs/credits">点数如何运作</a> 与 <a href="/zh-cn/docs/topup">充值与钱包</a>。</p>
<h3 id="我怎么看花了多少">我怎么看花了多少？</h3>
<p>Usage 页依模型与 key 汇整 credits 与 tokens；request logs 提供每笔请求的稽核轨迹。见 <a href="/zh-cn/docs/monitoring">用量与纪录</a> 与 <a href="/zh-cn/docs/spend">追踪消耗</a>。</p>
<h3 id="为什么-reasoning-模型回传-200-但内容是空的">为什么 reasoning 模型回传 200 但内容是空的？</h3>
<p><code>max_tokens</code> 设太低了。reasoning(extended thinking)模型的思考会吃同一个额度；额度在产生可见输出前就用完，你会拿到空的 <code>200</code>——通常用量为零、也不会扣 credits。把 <code>max_tokens</code> 调高到「思考+预期输出」都够用。见<a href="/zh-cn/docs/errors">常见响应</a>。</p>
