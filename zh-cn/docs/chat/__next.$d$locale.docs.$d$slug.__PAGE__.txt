<p><code>POST /v1/responses</code> 是同一个 SDK 的另一个入口（OpenAI Responses API），不是另一种模型。body 和 chat completions 不同：</p>
<ul>
<li>用 <code>input</code> 取代 <code>messages</code>。</li>
<li>系统提示放 <code>instructions</code>。</li>
<li>输出上限是 <code>max_output_tokens</code>。</li>
<li>function tool 是扁平结构：<code>{type:&quot;function&quot;, name, parameters}</code>。</li>
<li>不保存对话状态：<code>store</code> 和 <code>previous_response_id</code> 会被忽略，所以每一轮都要送完整的 <code>input</code>。</li>
</ul>
