# 团队与角色

> Source: https://atptoken.ai/zh-cn/docs/team/

Team organization 可以加人，并在 workspace 或 project 层级指派角色。共有三种角色：

| 角色 | 可以做什么 |
|---|---|
| Owner | 完整控制权。在 UI 中为唯读，且无法被移除。 |
| Admin | 管理成员、资源、key 与 credit 分配。 |
| Member | 读取并使用自己有权限的部分。 |

**以 email 邀请** 会寄出一封需对方接受的邀请；**加入既有使用者** 则会立即挂上一个已存在的账号。Personal organization 没有团队，会显示一段说明取代成员面板。
