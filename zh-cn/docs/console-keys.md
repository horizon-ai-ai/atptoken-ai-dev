# 管理 API keys

> Source: https://atptoken.ai/zh-cn/docs/console-keys/

Create key 精灵会带你完成：命名 key、选择（或建立）workspace 与 project，并可选择顺便拨一笔起始 credits。一把 key 一律只属于一个 project，并继承该 project 的模型与 credit balance。

> **完整密钥只会显示一次**
>
> key 以 `atp-` 开头、长度 92 个字元。完整密钥只会在建立当下显示一次 — 请复制并妥善保存。之后只看得到 prefix。

**API keys** 页列出这个 organization 底下、跨所有 workspace 与 project 的每一把 key。可依名称或 prefix 搜寻、依 workspace 筛选，并随时撤销某把 key — 撤销后该 key 会立即失效，但仍会留在名册中供稽核。

以 project 为范围的 key 才能把花费与存取归帐。操作模式见 [一项目一密钥](https://atptoken.ai/zh-cn/blog/one-project-one-key/)。
