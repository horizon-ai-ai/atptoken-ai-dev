# 管理 API 密钥

> Source: https://atptoken.ai/zh-cn/docs/console-keys/

「建立 API 密钥」精灵会带你完成：命名密钥、选择（或建立）工作区与项目（project），并可选择顺便拨一笔起始点数。一把密钥一律只属于一个项目，并继承该项目的模型与点数余额。

> **完整密钥只会显示一次**
>
> 密钥以 `atp-` 开头、长度 92 个字元。完整密钥只会在建立当下显示一次——请复制并妥善保存。之后只看得到 prefix。

## 搜寻与撤销密钥

**API 密钥** 页列出这个组织底下、跨所有工作区与项目的每一把密钥。可依名称或 prefix 搜寻、依工作区筛选，并随时撤销某把密钥——撤销后该密钥会立即失效，但仍会留在名册中供稽核。

## 一个项目一把密钥

以项目为范围的密钥才能把花费与存取归帐。操作模式见 [一项目一密钥](https://atptoken.ai/zh-cn/blog/one-project-one-key/)。
