# 用量与记录

> Source: https://atptoken.ai/zh-cn/docs/monitoring/

有三个地方告诉你发生了什么、花了多少。

## 去哪里看

### 用量
点数摘要（可用、已收到、已用）、当月热门模型，以及每把密钥的 token 总量。
### 请求记录
每笔请求的稽核轨迹。可依时间范围、范围、模型、状态或 request ID 筛选；栏位依序是时间、模型、模态、端点、调用身份、状态与点数。
### 活动记录
安全与管理事件——登录、邀请、额度变更与资源更新。

## 怎么读这些数字

时间戳记依你的本地时区显示。Token 数为原始总数，不是 per-million。
