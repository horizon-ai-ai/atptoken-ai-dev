# 用量与纪录

> Source: https://atptoken.ai/zh-cn/docs/monitoring/

有三个地方告诉你发生了什么、花了多少：

### Usage
Credit 摘要（Available、Received、Consumed）、当月热门模型，以及每把 key 的 token 总量。
### Request logs
每笔请求的稽核轨迹。可依时间范围、范围、模型、状态或 request ID 筛选；栏位显示状态与 input / output tokens。
### Activity
安全与管理事件 — 登入、邀请、额度变更与资源更新。

时间戳记依你的本地时区显示。Token 数为原始总数，不是 per-million。
