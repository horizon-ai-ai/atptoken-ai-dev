# 设定你的组织

> Source: https://atptoken.ai/zh-cn/docs/console-setup/

控制台里的一切都挂在一个四层结构下。你只会建立一次组织，然后在里面层层放进工作区、项目（project）与密钥。

## 四个层级

| 层级 | 装什么 |
|---|---|
| 组织 | 账单与团队的边界。分 Personal 或 Team。 |
| 工作区 | 一个点数容器，把相关的项目分在一起。 |
| 项目 | 设定允许的模型清单，并持有一份点数余额。 |
| API 密钥 | 范围受限的凭证，继承所属项目的模型与点数。 |

## 建立组织

首次登录时，onboarding 会请你输入组织名称（会自动产生一个选填的小写 slug）。**Team** 组织可以邀请成员并指派角色；**Personal** 组织为单人使用，并会隐藏 Team 页。

## 下一步

- [工作区与项目](https://atptoken.ai/zh-cn/docs/resources/) — 建立工作区与项目，并把点数分配下去。
- [管理 API 密钥](https://atptoken.ai/zh-cn/docs/console-keys/) — 建立只属于一个项目的密钥。
- [团队与角色](https://atptoken.ai/zh-cn/docs/team/) — 邀请成员加入 Team 组织并指派角色。
