The name· 名字的来源

名字是怎么来的

完整的名字是 Agent Token Petrichor。三个字里有两个在讲平台怎么运作——谁在花、用什么计价；第三个字只是名字的来源。

缩写不是巧合。生物学里，ATP（三磷酸腺苷）是细胞的能量货币：无论能量从哪里来，都得先换成 ATP，身体才用得上。算力也是同一个道理——它得先变成 token，企业才真正花得出去。而这道转换、以及转换的计量与账，就是我们工作的那一层。

Agent谁在花

请求不再来自坐在键盘前的人，而是来自会自己循环、重试、调用工具的代理程序——这正是花费需要一套结构的原因：它不能靠某个人记得去看一眼。

Token用什么计价

Token 是智慧真正的计价单位。每一笔请求都以它计量、归属到项目、以点数结算——成本不再是每月的意外，而是每一次调用都有的一个数字。

Petrichor名字的来源

Petrichor 是一个少用的英文字，语源来自希腊文（petra + ichor）。它在这里只有一个作用：解释名字怎么来的——不是产品隐喻，也不构成品牌承诺。平台的承诺是白话的那一句——算力成为有归属、有账的行动。完整名称只留在法律实体与早期资料里，产品名是 ATP Token。
