FAQ

3
What does Wan 3.0 (Video) produce?
Wan 3.0 (Video) is an Alibaba Cloud video generation model. It returns video clips at 720P / 1080P. The video generation docs list the inputs it accepts.
How is Wan 3.0 (Video) priced?
You pay per second of video. The price depends on the resolution you pick (720P / 1080P). The pricing section also lists prices per 1M video tokens by resolution. You only pay when a request succeeds. $1 = 100 credits. See pricing
How do I call Wan 3.0 (Video) on ATP?
Create a project API key. Check that "wan-3-0-video" shows up with GET https://api.atptoken.ai/v1/models, then follow the video generation docs with model set to that id.
