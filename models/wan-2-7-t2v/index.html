FAQ

How much does Wan 2.7 (Text→Video) cost on ATP Token?
List rates for Wan 2.7 (Text→Video) (API id wan-2-7-t2v): 720P $0.10 · 1080P $0.15 per second. Billing uses credits (1 USD = 100 credits), debited from the project balance per completed request. There is no monthly platform fee; see Pricing for the minimum top-up.
How do I call Wan 2.7 (Text→Video) via API?
Create a project API key, enable the API id wan-2-7-t2v (not the display name) on that project’s allowlist, point an OpenAI-compatible SDK at https://api.atptoken.ai/v1, and set model to "wan-2-7-t2v". See the Quickstart on this page and the docs.
What are the context and capabilities of Wan 2.7 (Text→Video)?
Capability flags (thinking, tools, vision) follow the gateway model catalog — treat the catalog visible to your key as operational truth. Context is shown only when we have a reliable source. Vendor: Alibaba Cloud.
Who can use Wan 2.7 (Text→Video) on ATP?
Only models on a project’s allowlist can be called with that project’s key (match the API id). Organization → workspace → project governance, per-request logs, and credit budgets are managed in the ATP Console.
