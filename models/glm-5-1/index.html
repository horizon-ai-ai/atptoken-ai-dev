FAQ

4
Can GLM-5.1 use tools, read images, or think before answering?
GLM-5.1 supports tool calling and extended thinking, but not vision input or audio.
How is GLM-5.1 priced?
You pay per 1M input tokens and per 1M output tokens. You only pay when a request succeeds. $1 = 100 credits. See pricing
Is there a newer Z.ai model than GLM-5.1 on ATP?
Yes. GLM-5.2 (glm-5-2) came out on Jun 16, 2026, after GLM-5.1 (Apr 7, 2026), and is the newer Z.ai text option on ATP. Both stay available: compare family prices on this page, then turn on the id you want for your project.
How do I call GLM-5.1 on ATP?
Create a project API key and point any OpenAI-compatible SDK at https://api.atptoken.ai/v1. Set model to "glm-5-1" (the API id, not the display name). Make sure the model is turned on for your project.
