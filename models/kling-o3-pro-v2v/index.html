FAQ

How much does Kling O3 Pro (Video→Video) cost on ATP Token?
List rates for Kling O3 Pro (Video→Video) (API id kling-o3-pro-v2v): 1080P $0.168 per second. Billing uses credits (1 USD = 100 credits), debited from the project balance per completed request. There is no monthly platform fee; see Pricing for the minimum top-up.
How do I call Kling O3 Pro (Video→Video) via API?
Create a project API key, enable the API id kling-o3-pro-v2v (not the display name) on that project’s allowlist, point an OpenAI-compatible SDK at https://api.atptoken.ai/v1, and set model to "kling-o3-pro-v2v". See the Quickstart on this page and the docs.
What are the context and capabilities of Kling O3 Pro (Video→Video)?
Capability flags (thinking, tools, vision) follow the gateway model catalog — treat the catalog visible to your key as operational truth. Context is shown only when we have a reliable source. Vendor: Kuaishou (Kling).
Who can use Kling O3 Pro (Video→Video) on ATP?
Only models on a project’s allowlist can be called with that project’s key (match the API id). Organization → workspace → project governance, per-request logs, and credit budgets are managed in the ATP Console.
