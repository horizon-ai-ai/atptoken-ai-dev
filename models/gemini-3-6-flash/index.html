FAQ

How much does Gemini 3 6 Flash cost on ATP Token?
List rates for Gemini 3 6 Flash (API id gemini-3-6-flash): input $1.50 / output $7.50 per 1M tokens. Billing uses credits (1 USD = 100 credits), debited from the project balance per completed request. There is no monthly platform fee; see Pricing for the minimum top-up.
How do I call Gemini 3 6 Flash via API?
Create a project API key, enable the API id gemini-3-6-flash (not the display name) on that project’s allowlist, point an OpenAI-compatible SDK at https://api.atptoken.ai/v1, and set model to "gemini-3-6-flash". See the Quickstart on this page and the docs.
What are the context and capabilities of Gemini 3 6 Flash?
Capability flags (thinking, tools, vision) follow the gateway model catalog — treat the catalog visible to your key as operational truth. Context is shown only when we have a reliable source. Vendor: Google.
Who can use Gemini 3 6 Flash on ATP?
Only models on a project’s allowlist can be called with that project’s key (match the API id). Organization → workspace → project governance, per-request logs, and credit budgets are managed in the ATP Console.
