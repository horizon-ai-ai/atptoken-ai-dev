FAQ

3
Can GPT-5.6 Luna use tools, read images, or think before answering?
Tool calling: yes. Vision input: yes. Extended thinking: yes. Audio: no. These come from the ATP model catalog, so check with your key before you rely on one.
How is GPT-5.6 Luna priced?
You pay per 1M input tokens and per 1M output tokens. You only pay when a request succeeds. $1 = 100 credits. See pricing
How do I call GPT-5.6 Luna on ATP?
Create a project API key and point any OpenAI-compatible SDK at https://api.atptoken.ai/v1. Set model to "gpt-5.6-luna" (the API id, not the display name). Make sure the model is turned on for your project.
