ATP Token MCP server

The MCP server is https://mcp.atptoken.ai/mcp (Streamable HTTP), named atptoken-api-docs. This page is not the endpoint itself. No key is needed to add it.

ATP 的 MCP 網址是 https://mcp.atptoken.ai/mcp，這一頁不是 MCP 端點本身。加上它不需要金鑰。

Add it

claude mcp add --transport http --scope user atptoken-api-docs https://mcp.atptoken.ai/mcp
codex mcp add atptoken-api-docs --url https://mcp.atptoken.ai/mcp

Claude app, ChatGPT, Cursor, Cline, Gemini CLI and other tools: paste-ready setup for each is at Add the ATP MCP server (Markdown). Start a new session afterwards so the tools load.

What it gives your assistant

  • atptoken_docs: the ATP API guide and call order
  • atptoken_list_models: which models your key's project allows (needs your ATP key)
  • atptoken_check_media_request: checks a video request before you send it
  • atptoken_install: install commands for more tools

Making pictures, videos or speech, or running your assistant on ATP models, uses an ATP API key from the console.
