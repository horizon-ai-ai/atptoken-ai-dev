适合场景

适合
  • 一次生成、同时带有音效的电影感短片
  • 以图片与视频参考保持角色与场景一致的参考式生成
  • 以首尾帧锁定画面、控制转场的镜头
  • 先用 Seedance 2.0 Fast 试 prompt，再出正式成片
通常较不适合
  • 快速、低成本的反复试作——ATP 上的 Seedance 2.0 Fast 更快也更省
  • 超过 15 秒的单条连续视频——更长的作品需由多段视频拼接

常见问题

3
Seedance 2.0 可以输入什么、会生成什么？
Seedance 2.0 是 ByteDance (Seedance) 的视频生成模型。输入文本提示（可附图片或视频），生成视频（480p / 720p / 1080p / 4k）。纯文本和带图／视频的请求价格不同。
Seedance 2.0 怎么计价？
按视频秒数计价，每秒价格取决于你选的分辨率（480p / 720p / 1080p / 4k）。价格区也列出各分辨率每百万视频 Token 的价格。请求成功才扣点，失败不收费。USD 1＝100 点。 查看价格
怎么通过 ATP 调用 Seedance 2.0？
创建项目 API 密钥，先用 GET https://api.atptoken.ai/v1/models 确认能看到「seedance-2-0」，再按视频生成文档发请求，model 填这个代号。
