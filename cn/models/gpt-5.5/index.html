适合场景

适合
  • 在大量工具与多步服务流程间运作的重度工具代理
  • 编码助手，以及把产品规格转成具体执行计划
  • 在 1.05M token 窗口内运作的有依据助手与长上下文检索
  • 想降低推理 token 用量的现有 GPT-5.4 代理循环
通常较不适合
  • 更适合 GPT-5.6 Luna 价位的大量摘要或例行自动化
  • 极限难度推理与长程代理工作（可评估 GPT-5.6 Sol）

快速上手

沿用你的 SDK：把 base_url 指向 ATP，换上项目密钥就行。 阅读文档
quickstart.py · OpenAI SDK
from openai import OpenAI

client = OpenAI(
  base_url="https://api.atptoken.ai/v1",
  api_key="atp-•••"
)

r = client.chat.completions.create(
  model="gpt-5.5",
  messages=[{"role":"user","content":"hi"}],
)
