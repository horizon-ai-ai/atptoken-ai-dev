常见问题

Claude Haiku 4.5 在 ATP Token 上多少钱？
Claude Haiku 4.5（API：claude-haiku-4-5）的 USD 刊例为：每百万 Token 输入 1.00 美元、输出 5.00 美元。计费单位为点数（1 美元 = 100 点数），按完成请求从项目余额扣款；无月费、最低充值见定价页。
如何用 API 调用 Claude Haiku 4.5？
签发项目 API 密钥，在项目白名单启用代号 claude-haiku-4-5（不是显示名称），将 OpenAI 兼容 SDK 的 base_url 指向 https://api.atptoken.ai/v1，model 参数必须设为「claude-haiku-4-5」。详见本页 Quickstart 与文档。
Claude Haiku 4.5 的上下文与能力？
深度思考、工具、视觉等能力旗标依网关模型目录回报，实际以你密钥可见的目录为准；上下文数字有可靠来源才会标示。供应商为 Anthropic。
谁可以调用 Claude Haiku 4.5？
仅项目允许列表中的模型代号可被该项目密钥调用。组织／工作区／项目分层治理、逐请求记录与点数预算均在 ATP Console 管理。
