03 / 选用

什么时候选哪个

按厂商文档整理各家族更适合的场景。价格以外的事实都列在下方资料来源。

选 Gemini，如果你要

  • 同一个请求里混合文本、图片、视频、音频与 PDF 的多模态流水线——Google 文档为 Gemini 3.5 Flash 与 Gemini 3 系列记载了这些输入。
  • 以 Flash 单价运行的成本敏感型智能体循环。Google 把 Gemini 3 Flash 定位为「Flash 延迟、Pro 级推理」，并自报 SWE-bench Verified 78%。
  • 在单一会话内理解整个代码库或长文档：Google 文档记载 Gemini 3.1 Pro（Preview）与 3.5 Flash 有 1M Token 上下文。
  • 逐次调整推理深度——Gemini 3.x 提供思考等级（minimal 到 high），同一个模型代号可以同时服务快速与深思的请求。
全部 Gemini 模型

选 GPT，如果你要

  • 以 OpenAI 工具链打造的编程智能体与电脑操作自动化。OpenAI 把 GPT-5.4 定位在编程智能体、电脑操作与长程工具链，并表示 GPT-5.5 完成相同 Codex 任务所用的 Token 比 GPT-5.4 少很多。
  • 以中价位运行的正式商务流量：OpenAI 形容 GPT-5.6 Terra 表现与 GPT-5.5 相当、成本约一半。
  • 重试代价很高的前沿推理——GPT-5.6 Sol 与 GPT-5.4 Pro 是 OpenAI 的最高档，只把最难的调用送过去。
  • 需要明确上下文数字的超长文档：OpenAI 文档记载 GPT-5.4 为 1,050,000 Token。

04 / 治理

一个密钥，两个都用

通常不必只选一个。在 ATP 上两个家族都在同一个端点、同一个项目密钥后面——每个任务送到最适合的模型，依然只有一份预算、一份允许清单、一份记录。

  • 一个项目密钥——用量与撤销都绑定在单一项目
  • 模型允许清单——只有你开启的模型代号能被调用，其余返回 403
  • 项目预算——点数由组织 → 工作区 → 项目往下配额，配额就是上限
  • 逐请求记录、一张账单——两家厂商的每次调用都记下模型、密钥、项目与点数
two_models.py · OpenAI SDK
from openai import OpenAI

# one project key; both ids must be on the project's allowlist
client = OpenAI(base_url="https://api.atptoken.ai/v1", api_key="atp-•••")

def ask(model, prompt):
    r = client.chat.completions.create(
        model=model, messages=[{"role": "user", "content": prompt}]
    )
    return r.choices[0].message.content

draft = ask("gemini-3-5-flash", "Summarize this ticket…")
final = ask("gpt-5.5", "Review: " + draft)

# both calls: same log, same credit balance, same budget

Gemini 和 GPT 哪个更便宜？
按 ATP 价格（每百万 Token 美元）计，Gemini 从 gemini-3-5-flash-lite 的 $0.30 / $2.50 到 gemini-3-1-pro-preview 的 $2.00 / $12.00；GPT 从 gpt-5.6-luna 的 $1.00 / $6.00 到 gpt-5.4-pro 的 $30.00 / $180.00。实际谁更便宜，取决于你的输入／输出比例与需要哪一档模型——本页的试算器会用同一份工作量把每个模型都算一遍。
Gemini 和 GPT 哪个上下文更长？
有文档记载的上下文长度——Gemini：Gemini 3.5 Flash 1.05M、Gemini 3.5 Flash Lite 1.05M。GPT：GPT-5.4 Pro 1.05M、GPT-5.5 1.05M、GPT-5.4 1.05M。表格中标「—」的模型，我们手上没有原厂出处，因此不写数字。
两边哪些档位可以互相对照？
看角色、不看名字：Gemini 3.1 Pro（Preview）对 GPT-5.4／GPT-5.5，处理吃重的工作；Gemini 3.5／3.6 Flash 对 GPT-5.6 Terra，跑正式量；Gemini 3.5 Flash-Lite 与 3 Flash（Preview）对 GPT-5.6 Luna，跑最便宜的大批量调用。先看上面表格的价格，再用试算器算你自己的比例。
Gemini 和 GPT 可以用同一个 API 密钥吗？
可以。在 ATP 上两个家族都在同一个 OpenAI 兼容端点（https://api.atptoken.ai/v1）后面，Anthropic 格式的客户端也能走 /v1/messages。一个项目密钥可以调用该项目模型允许清单上的任何模型；每笔请求都写进同一份逐请求记录、从同一个点数余额扣款。
怎么让团队只用我们批准的模型？
用项目的模型允许清单：只开启批准过的模型代号，调用其他代号会被拒绝（403）。再给项目一笔独立的点数配额，预算就是上限；每个模型花了多少，逐请求记录里都看得到。
