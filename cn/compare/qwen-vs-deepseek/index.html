03 / 选用

什么时候选哪个

按厂商文档整理各家族更适合的场景。价格以外的事实都列在下方资料来源。

选 Qwen，如果你要

  • 依赖严格工具调用格式的工具型与终端智能体。阿里在 Qwen 3.6 Max 的发布资料中，表示它在自家编程与智能体评测组（含 SWE-bench Pro、Terminal-Bench 2.0）取得第一（厂商自报）。
  • 中英双语助手与内容流水线——阿里表示 3.6 Max 在中文表现上有可量化的提升。
  • 非常短、非常频繁的请求：Flash 档最低一段输入分段就是为短提示词定价的，路由、标注类调用因此很便宜。
  • 想在同一家厂商内有三档可升降——Max 求深度、Plus 做日常、Flash 跑量——且命名一致的团队。
全部 Qwen 模型

选 DeepSeek，如果你要

  • 长提示词、单一费率。DeepSeek V4 不论请求多长都是同一个价，两个 V4 模型都记载 1M Token 上下文——不用为分段加价做规划。
  • 需要推理的编程与分析：V4 Pro 默认开启思考模式，可逐请求关闭，输出上限 384K。
  • 重复前缀的工作负载——共享系统提示词、RAG 模板——DeepSeek 的缓存读费率能在命中时压低输入成本。
  • 预算有限但需要图片输入的流程：ATP 目录中两个 V4 模型都标示视觉能力，这里的 Qwen 文本档则只收文本。
全部 DeepSeek 模型
04 / 治理

一个密钥，两个都用

通常不必只选一个。在 ATP 上两个家族都在同一个端点、同一个项目密钥后面——每个任务送到最适合的模型，依然只有一份预算、一份允许清单、一份记录。

  • 一个项目密钥——用量与撤销都绑定在单一项目
  • 模型允许清单——只有你开启的模型代号能被调用，其余返回 403
  • 项目预算——点数由组织 → 工作区 → 项目往下配额，配额就是上限
  • 逐请求记录、一张账单——两家厂商的每次调用都记下模型、密钥、项目与点数
two_models.py · OpenAI SDK
from openai import OpenAI

# one project key; both ids must be on the project's allowlist
client = OpenAI(base_url="https://api.atptoken.ai/v1", api_key="atp-•••")

def ask(model, prompt):
    r = client.chat.completions.create(
        model=model, messages=[{"role": "user", "content": prompt}]
    )
    return r.choices[0].message.content

draft = ask("qwen-3-7-flash", "Summarize this ticket…")
final = ask("deepseek-v4-pro", "Review: " + draft)

# both calls: same log, same credit balance, same budget

Qwen 和 DeepSeek 哪个更便宜？
按 ATP 价格（每百万 Token 美元）计，Qwen 从 qwen-3-7-flash 的 $0.03 / $0.13 到 qwen-3-6-max 的 $1.29 / $7.71；DeepSeek 从 deepseek-v4-flash 的 $0.20 / $0.40 到 deepseek-v4-pro 的 $2.40 / $4.80。实际谁更便宜，取决于你的输入／输出比例与需要哪一档模型——本页的试算器会用同一份工作量把每个模型都算一遍。
ATP 上 Qwen 的分段计价怎么算？
有输入分段的 Qwen 模型，级距按单次请求的输入 Token 总量判定（含缓存命中的 Token），并适用于该次请求的全部用量，输出亦同。短请求停在最低一段，很长的请求会进入较高费率。这里的试算器会按你输入的大小选分段。
Qwen 和 DeepSeek 哪个上下文更长？
有文档记载的上下文长度——Qwen：暂无原厂资料。DeepSeek：DeepSeek V4 Pro 1M、DeepSeek V4 Flash 1M。表格中标「—」的模型，我们手上没有原厂出处，因此不写数字。
Qwen 和 DeepSeek 可以用同一个 API 密钥吗？
可以。在 ATP 上两个家族都在同一个 OpenAI 兼容端点（https://api.atptoken.ai/v1）后面，Anthropic 格式的客户端也能走 /v1/messages。一个项目密钥可以调用该项目模型允许清单上的任何模型；每笔请求都写进同一份逐请求记录、从同一个点数余额扣款。
怎么让团队只用我们批准的模型？
用项目的模型允许清单：只开启批准过的模型代号，调用其他代号会被拒绝（403）。再给项目一笔独立的点数配额，预算就是上限；每个模型花了多少，逐请求记录里都看得到。
