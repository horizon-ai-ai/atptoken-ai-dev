在 ATP 上

团队如何在 ATP 上使用 OpenAI

同样的 OpenAI 模型，外加公司需要的管控：谁能从哪个项目调用哪个模型、预算多少，每笔请求都有记录。

  • 项目 API 密钥

    每把密钥隶属一个项目，继承该项目的模型与余额；任何时候都能单独撤销，不影响其他密钥。

  • 项目模型允许清单

    只启用项目需要的 OpenAI 模型；清单外的模型，该项目的密钥调用不到。

  • 预算

    点数由组织分配到工作区、再到项目；分配额就是上限，一个团队花不到别人的预算。

  • 逐笔请求记录

    每次调用都记下项目、密钥、模型、用量与扣点，花费可以追到单一请求。

  • 一个钱包、一张账单

    OpenAI 与 ATP 上其他 10 家供应商共用同一份预付点数，不必各签合同、各收账单。

quickstart.py · OpenAI SDK
from openai import OpenAI

client = OpenAI(
  base_url="https://api.atptoken.ai/v1",
  api_key="atp-•••",
)

r = client.chat.completions.create(
  model="gpt-5.6-luna",
  messages=[{"role": "user", "content": "hi"}],
)
print(r.choices[0].message.content)

把现有 SDK 或 HTTP 客户端指向 ATP，设置模型代号即可。用 GET /v1/models 确认你的密钥能调用哪些模型。 完整说明见文档

如何通过 ATP Token 调用 OpenAI API？
创建项目 API 密钥，在该项目的模型允许清单启用要用的 OpenAI 模型代号，再把 OpenAI 兼容 SDK 的 base_url 指向 https://api.atptoken.ai/v1，model 设为模型代号（例如 gpt-5.6-luna）。
OpenAI API 在 ATP Token 上多少钱？
ATP Token 上 9 个 OpenAI 模型的价格（USD）：每百万 Token 输入 $1.00–$30.00、输出 $6.00–$180.00；嵌入每百万 Token $0.022–$0.143。以点数计费（USD 1＝100 点），请求成功才从项目扣点，失败不收费；无月费，USD 5 起充值。
ATP Token 上最便宜的 OpenAI 模型是哪个？
按价格（各模态分开比较）：文本：GPT-5.6 Luna (gpt-5.6-luna)，每百万 Token 输入 $1.00、输出 $6.00；嵌入：Text Embedding 3 Small (text-embedding-3-small)，每百万 Token 输入 $0.022；图像：GPT Image 2 (gpt-image-2)，每百万 Token 输入 $5.00、输出 $30.00。
ATP Token 上最新的 OpenAI 模型有哪些？
本站列出的 OpenAI 模型中，最新发布的是 GPT-5.6 Sol (gpt-5.6-sol)、GPT-5.6 Terra (gpt-5.6-terra)、GPT-5.6 Luna (gpt-5.6-luna)（OpenAI 于 2026 年 7 月 9 日 发布）。完整清单可用 GET /v1/models 列出。
OpenAI 模型支持工具调用与视觉输入吗？
依 ATP 模型目录的能力旗标：6 个文本模型中 6 个支持工具调用、6 个支持视觉（图片）输入、6 个支持深度思考。各模型能力也列在上方表格。
团队怎么管控谁能用 OpenAI 模型、花多少？
每个项目有自己的 API 密钥与模型允许清单：清单外的 OpenAI 模型，该项目密钥调用不到。点数由组织、工作区分配到项目，可设预算上限；每笔请求记录项目、密钥、模型与扣点，所有供应商共用一个钱包、一张账单。
