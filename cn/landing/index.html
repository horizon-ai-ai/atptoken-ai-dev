Models· 多模型路由

三种 API 介面,同一个网关,所有模型。

用你的 SDK 本来就会的介面调用。网关把它路由到该模型的供应商池,密钥仍只限所属项目,每一笔请求都计量。

三种介面,同一把密钥

  • OpenAI SDK
    /v1/chat/completionsclient.chat.completions.create(model, messages)
  • Anthropic Messages
    /v1/messagesclient.messages.create(model, max_tokens, messages)
  • Gemini-style
    /v1beta/models/…:generateContentgenerateContent(model, contents)

OpenAI 兼容

沿用同一套 SDK 写法,只需换掉 base URL。

项目范围控管

每把密钥只能使用所属项目启用的模型。

自动容错切换

通过该模型设定的供应商池路由与备援。

可实时发现
