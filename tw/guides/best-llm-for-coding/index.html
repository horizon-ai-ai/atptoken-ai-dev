04 / 治理

替程式代理設預算

程式代理會反覆送出程式庫上下文、在工具間來回、失敗就重試，每完成一個改動用掉的 Token 遠高於一次對話。把它當成一個產品面來管：獨立的專案、金鑰、允許清單與上限。

  • 替代理開獨立專案與金鑰，實驗不會吃掉正式環境的預算
  • 以固定點數配額當上限，在用量頁看「已配額／已使用」
  • 模型允許清單預設不開前沿模型——要升級就刻意升級
  • 用逐請求紀錄追蹤「每完成一個任務花多少點數」與花費最高的模型

05 / 常見問題

團隊常問的問題

常見問題

5
寫程式最好的 LLM 是哪個？
要看工作內容，我們不發布通用排名。代理式開發的預設模型，常見起點是 Claude Sonnet 5 與 GPT-5.5；低成本的迴圈步驟可用 Gemini 3 Flash（Preview）或 DeepSeek V4 Flash；要開放權重可選 Kimi K2.7 Code 或 GLM-5.2；最難的任務再升級到 Claude Opus 4.8 這類模型。挑兩三個在你自己的程式庫上試，比較「每完成一個任務花多少點數」。
哪個 LLM 跑程式代理最便宜？
以 ATP 牌價與本頁的工作量（每個任務 30 次模型呼叫、每次輸入 20K＋輸出 1K Token，10 位開發者 × 每人每月 100 個任務）計算，最低的是 Qwen 3.7 Flash，未計快取約每個任務 $0.02。每 Token 最便宜不等於每完成一個任務最便宜：需要更多步驟或重試的模型，總成本可能更高。
看評測分數就能決定用哪個模型嗎？
只能當粗略參考。廠商自報的分數用的是不同套件（SWE-bench Verified、SWE-bench Pro、Terminal-Bench、自家評測）、不同版本與執行框架，一家的數字不能拿來跟另一家比。用它們列出候選，再用你自己的任務實測。
一個程式代理每個月要花多少？
依本頁假設（每個任務 30 次模型呼叫、每次輸入 20K＋輸出 1K Token，10 位開發者 × 每人每月 100 個任務），10 人團隊使用 Claude Sonnet 5，未計快取的牌價約每月 $1,500。有快取讀費率的模型，提示快取命中可以大幅降低；重試與較長的任務則會推高。
怎麼替程式代理的花費設上限？
給代理獨立的專案與金鑰、替該專案配一筆固定點數預算（配額就是上限）、非必要不把前沿模型放進允許清單，每週用逐請求紀錄檢視每個任務花了多少點數。
