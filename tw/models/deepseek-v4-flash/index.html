常見問題

4
DeepSeek V4 Flash 能呼叫工具、看圖或深度思考嗎？
工具呼叫：有。看圖：有。深度思考：無。語音：無。以上來自 ATP 模型目錄，上線前用你的金鑰再確認一次。
DeepSeek V4 Flash 的上下文有多長？
DeepSeek 標示 DeepSeek V4 Flash 的上下文窗口是 1,000,000 tokens。來源：DeepSeek API Docs — Models & Pricing（查核於 2026-10-01）。實際上限請看你的金鑰可見的模型目錄。
DeepSeek V4 Flash 的快取輸入比較便宜嗎？
按每百萬輸入 Token 和每百萬輸出 Token 計價。快取命中的輸入只收一般輸入價格的 20%。請求成功才扣點，失敗不收費。1 美元 = 100 點數。 查看價格
怎麼透過 ATP 呼叫 DeepSeek V4 Flash？
建立專案 API 金鑰，把 OpenAI 相容 SDK 的 base_url 指向 https://api.atptoken.ai/v1，model 填「deepseek-v4-flash」（是 API 代號，不是顯示名稱）。記得先在專案裡開啟這個模型。
