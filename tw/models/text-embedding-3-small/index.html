  base_url="https://api.atptoken.ai/v1",
  api_key="atp-•••"
)

r = client.embeddings.create(
  model="text-embedding-3-small",
  input="petrichor",
)

Text Embedding 3 Small 能做什麼？
Text Embedding 3 Small 是 OpenAI 的嵌入模型。送入文字，取回向量，用來做搜尋、分群和相似度比對。
Text Embedding 3 Small 怎麼計價？
按每百萬輸入 Token 計價，輸出不收費。請求成功才扣點，失敗不收費。USD 1＝100 點。 查看價格
怎麼透過 ATP 呼叫 Text Embedding 3 Small？
建立專案 API 金鑰，把 OpenAI 相容 SDK 的 base_url 指向 https://api.atptoken.ai/v1，model 填「text-embedding-3-small」（是 API 代號，不是顯示名稱）。記得先在專案裡開啟這個模型。
