Qwen 3.7 Flash 能呼叫工具、看圖或深度思考嗎？
工具呼叫：有。看圖：無。深度思考：有。語音：無。以上來自 ATP 模型目錄，上線前用你的金鑰再確認一次。
Qwen 3.7 Flash 的分段價格怎麼算？
按每百萬輸入 Token 和每百萬輸出 Token 計價。價格依每次請求的輸入總長度分段（≤32K / 32K–256K / >256K）。整次請求都用同一段的價格，輸出也是。快取命中的輸入只收一般輸入價格的 20%。請求成功才扣點，失敗不收費。1 美元 = 100 點數。 查看價格
ATP 上有比 Qwen 3.7 Flash 更新的 Qwen (Alibaba) 模型嗎？
有。Qwen 3.8 Max (qwen-3-8-max) 在 2026 年 8 月 2 日 發布，比 Qwen 3.7 Flash（2026 年 7 月 21 日）新，是 ATP 上較新的 Qwen (Alibaba) 文字模型。兩個都能用：先在本頁比較同家族價格，再到專案裡開啟想用的代號。
怎麼透過 ATP 呼叫 Qwen 3.7 Flash？
建立專案 API 金鑰，把 OpenAI 相容 SDK 的 base_url 指向 https://api.atptoken.ai/v1，model 填「qwen-3-7-flash」（是 API 代號，不是顯示名稱）。記得先在專案裡開啟這個模型。
