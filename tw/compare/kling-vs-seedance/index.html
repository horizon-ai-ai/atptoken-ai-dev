    03 / 選用

    什麼時候選哪個

    依廠商文件整理各家族較適合的場景。價格以外的事實都列在下方資料來源。

    選 Kling，如果你要

    • 以 ATP 目前價格，720P 與 1080P 的每秒成本較低——見下方費率表。
    • 單一提示詞生成多鏡頭故事段落：快手在 3.0 發表中強調每次呼叫 2–6 個相連鏡頭、單鏡最長 15 秒。
    • 編修既有影片：ATP 上的 O3 系列有影片轉影片、自然語言影片編修，以及最多七張參考圖的參考模式。
    • 無聲片段：Kling 的音訊生成在 ATP 上尚未開放，聲音在後製加時選 Kling。
    全部 Kling 模型

    選 Seedance，如果你要

    • 要連同生成音訊一起交付的片段——Seedance 2.0 在 ATP 上支援可選的生成音訊。
    • 高度條件化的生成：字節跳動的技術報告記載每次生成最多 12 個文字、圖片、影片與音訊素材，並可控制首尾幀。
    • 同一個模型涵蓋更寬的解析度階梯：ATP 上 seedance-2-0 從 480p 到 4k 都能出，草稿與定稿用同一個代號。
    • 定稿前的快速迭代：seedance-2-0-fast 以較低的解析度上限（720p）換取較低的每秒單價。

    04 / 治理

    一把金鑰，兩個都用

    通常不必只選一個。在 ATP 上兩個家族都在同一個端點、同一把專案金鑰後面——每個任務送到最適合的模型，仍然只有一份預算、一份允許清單、一份紀錄。

    • 一把專案金鑰——用量與撤銷都綁定在單一專案
    • 模型允許清單——只有你開啟的模型代號能被呼叫，其餘回 403
    • 專案預算——點數由組織 → 工作區 → 專案往下配額，配額就是上限
    • 逐請求紀錄、一張帳單——兩家廠商的每次呼叫都記下模型、金鑰、專案與點數
    two_models.py · requests
    import requests

URL = "https://api.atptoken.ai/omni/media/v1/contents/generations/tasks"
H = {"Authorization": "Bearer atp-•••"} # one project key

for model in ["kling-v3-standard", "seedance-2-0-fast"]:
    task = requests.post(URL, headers=H, json={
        "model": model, "resolution": "720p", "duration": 5,
        "content": [{"type": "text", "text": "a red fox running through snow"}],
    }).json()
    print(model, task["id"]) # 202 → poll the task until it succeeds
    05 / 常見問題

    團隊常問的問題

    常見問題

    5
    每秒成本 Kling 和 Seedance 哪個便宜？
    以 ATP 價格計，Kling 從 $0.084/s (720P)（kling-v3-standard）到 $0.168/s (1080P)（kling-o3-pro-video-edit）；Seedance 從 $0.0538/s (480p)（seedance-2-0-fast）到 $0.7776/s (4k)（seedance-2-0）。請比較相同解析度：本頁的費率表已依級別排好。
    範例片段是用完全相同的設定生成的嗎？
    提示詞逐字相同；解析度與秒數則不同：每個模型都以自己的上限生成，所以可能一支是 1080p／8 秒、另一支是 720p／10 秒。每張卡都標示該模型實際產出的規格，數字從檔案實測。
    Kling 和 Seedance 會生成聲音嗎？
    在 ATP 上，Seedance 2.0 支援可選的生成音訊；Kling 的音訊生成在 ATP 上尚未開放，Kling 片段為無聲。本頁的範例片段皆為無聲。
    Kling 和 Seedance 可以用同一把 API 金鑰嗎？
    可以。在 ATP 上兩個家族走同一支非同步影片端點（POST /omni/media/v1/contents/generations/tasks），用同一把 atp- 專案金鑰，換 model 欄位即可切換。影片模型需經允許清單審核後才會在專案上開通，請洽業務啟用。
    怎麼讓團隊只用我們核准的模型？
    用專案的模型允許清單：只開啟核准過的模型代號，呼叫其他代號會被拒絕（403）。再給專案一筆獨立的點數配額，預算就是上限；每個模型花了多少，逐請求紀錄裡都看得到。
