03 / 選用

什麼時候選哪個

依廠商文件整理各家族較適合的場景。價格以外的事實都列在下方資料來源。

選 Gemini，如果你要

  • 同一個請求裡混合文字、圖片、影片、音訊與 PDF 的多模態流程——Google 文件為 Gemini 3.5 Flash 與 Gemini 3 系列記載了這些輸入。
  • 以 Flash 單價跑的成本敏感型代理迴圈。Google 把 Gemini 3 Flash 定位為「Flash 延遲、Pro 等級推理」，並自報 SWE-bench Verified 78%。
  • 在單一工作階段內理解整個程式庫或長文件：Google 文件記載 Gemini 3.1 Pro（Preview）與 3.5 Flash 有 1M Token 上下文。
  • 逐次調整推理深度——Gemini 3.x 提供思考等級（minimal 到 high），同一個模型代號可以同時服務快速與深思的請求。
全部 Gemini 模型

選 GPT，如果你要

  • 以 OpenAI 工具鏈打造的程式代理與電腦操作自動化。OpenAI 把 GPT-5.4 定位在程式代理、電腦操作與長程工具鏈，並表示 GPT-5.5 完成相同 Codex 任務用的 Token 比 GPT-5.4 少很多。
  • 以中價位跑的正式商務流量：OpenAI 形容 GPT-5.6 Terra 表現與 GPT-5.5 相當、成本約一半。
  • 重試代價很高的前沿推理——GPT-5.6 Sol 與 GPT-5.4 Pro 是 OpenAI 的最高級，只把最難的呼叫送過去。
  • 需要明確上下文數字的超長文件：OpenAI 文件記載 GPT-5.4 為 1,050,000 Token。

04 / 治理

一把金鑰，兩個都用

通常不必只選一個。在 ATP 上兩個家族都在同一個端點、同一把專案金鑰後面——每個任務送到最適合的模型，仍然只有一份預算、一份允許清單、一份紀錄。

  • 一把專案金鑰——用量與撤銷都綁定在單一專案
  • 模型允許清單——只有你開啟的模型代號能被呼叫，其餘回 403
  • 專案預算——點數由組織 → 工作區 → 專案往下配額，配額就是上限
  • 逐請求紀錄、一張帳單——兩家廠商的每次呼叫都記下模型、金鑰、專案與點數
two_models.py · OpenAI SDK
from openai import OpenAI

# one project key; both ids must be on the project's allowlist
client = OpenAI(base_url="https://api.atptoken.ai/v1", api_key="atp-•••")

def ask(model, prompt):
    r = client.chat.completions.create(
        model=model, messages=[{"role": "user", "content": prompt}]
    )
    return r.choices[0].message.content

draft = ask("gemini-3-5-flash", "Summarize this ticket…")
final = ask("gpt-5.5", "Review: " + draft)

# both calls: same log, same credit balance, same budget

常見問題

5
Gemini 和 GPT 哪個比較便宜？
以 ATP 價格（USD／每百萬 Token）計，Gemini 從 gemini-3-5-flash-lite 的 $0.30 / $2.50 到 gemini-3-1-pro-preview 的 $2.00 / $12.00；GPT 從 gpt-5.6-luna 的 $1.00 / $6.00 到 gpt-5.4-pro 的 $30.00 / $180.00。實際誰便宜，取決於你的輸入／輸出比例與需要哪一級模型——本頁的試算器會用同一份工作量把每個模型都算一遍。
Gemini 和 GPT 哪個上下文比較長？
有文件記載的上下文長度——Gemini：Gemini 3.5 Flash 1.05M、Gemini 3.5 Flash Lite 1.05M。GPT：GPT-5.4 Pro 1.05M、GPT-5.5 1.05M、GPT-5.4 1.05M。—：原廠未公布。
兩邊哪些級別可以互相對照？
看角色、不看名字：Gemini 3.1 Pro（Preview）對 GPT-5.4／GPT-5.5，處理吃重的工作；Gemini 3.5／3.6 Flash 對 GPT-5.6 Terra，跑正式量；Gemini 3.5 Flash-Lite 與 3 Flash（Preview）對 GPT-5.6 Luna，跑最便宜的大量呼叫。先看上面表格的價格，再用試算器算你自己的比例。
Gemini 和 GPT 可以用同一把 API 金鑰嗎？
可以。在 ATP 上兩個家族都在同一個 OpenAI 相容端點（https://api.atptoken.ai/v1）後面，Anthropic 格式的用戶端也能走 /v1/messages。一把專案金鑰可以呼叫該專案模型允許清單上的任何模型；每筆請求都寫進同一份逐請求紀錄、從同一個點數餘額扣款。
怎麼讓團隊只用我們核准的模型？
用專案的模型允許清單：只開啟核准過的模型代號，呼叫其他代號會被拒絕（403）。再給專案一筆獨立的點數配額，預算就是上限；每個模型花了多少，逐請求紀錄裡都看得到。
