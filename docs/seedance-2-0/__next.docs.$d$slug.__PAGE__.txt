<ul>
<li><strong><code>seedance-2-0</code> family (including fast and mini): <code>ratio</code> sets the output shape, not the first frame.</strong> <code>ratio</code> defaults to <code>16:9</code>, so a portrait first frame without a ratio gives a landscape video (864×496 at 480p), reframed. Send <code>ratio: &quot;adaptive&quot;</code> and the output follows the frame (portrait frame → 496×864).</li>
<li><strong><code>seedance-2-5</code>:</strong> with first and last frames, <strong>do not send <code>ratio</code></strong>. Without them you can, for example <code>ratio: &quot;16:9&quot;</code>.</li>
</ul>

<p>A public URL of a photo of a real person can be rejected with <code>400 … may contain real person</code>.
