3:T518,<p>Worth knowing before you render:</p>
<ul>
<li><strong>Aspect ratio changes the price.</strong> Cost follows actual width × height — a 1:1 clip at 720p costs ~44% less than 16:9 at the same tier.</li>
<li><strong>Auto duration bills actual seconds.</strong> With <code>duration: auto</code>, you are charged for the seconds the task actually renders, not the request.</li>
<li><strong>Reference video switches tiers.</strong> Adding input video moves the task to the with-input rate, and input seconds enter the formula.</li>
<li><strong>4K is not yet available</strong>; requests above 1080p are rejected before any task is created.</li>
<li><strong>Failed tasks are not billed.</strong></li>
</ul>
