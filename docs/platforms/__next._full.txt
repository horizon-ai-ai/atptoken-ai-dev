21:T4b2,<p>Two defaults cause most of the confusion. <strong>Model context size defaults to 4096</strong>, which silently truncates anything longer, so set it per model. And <strong>Function Call Type defaults to <code>no_call</code></strong>, which means Dify never sends a tools array — an agent built on that model will quietly refuse to call tools until you change it.</p>
<p>Dify does not read <code>GET /v1/models</code>, so each model is a separate Add Model entry. Call the endpoint first and work from the list it returns.</p>
<p>The setup is identical on Dify Cloud and self-hosted.</p>
<h2 data-md="h3" id="n8n">n8n</h2>
<p>n8n uses its built-in <strong>OpenAI</strong> credential. Create one, then under <strong>Add option</strong> set <strong>Base URL</strong> to <code>https://api.atptoken.ai/v1</code> and paste the <code>atp-…</code> key into <strong>API Key</strong>.</p>
<p>The model dropdown then reads <code>GET /v1/models</code> through that base URL, so your project&#39;s models appear without any manual list.</p>
<p>To use it, add an <strong>OpenAI Chat Model</strong> sub-node to an <strong>AI Agent</strong> or <strong>Basic LLM Chain</strong> node and select the credential.</p>22:T468,<p>Two more notes. The Base URL field lives on the credential, not on the node — it was hidden from the node in a later version, which is why it can look missing. And n8n&#39;s own docs do not list the field; it exists in the credential UI under <strong>Add option</strong>.</p>
<p>The credential behaves the same on n8n Cloud and self-hosted.</p>
<h2 data-md="h3" id="troubleshooting">Troubleshooting</h2>
<ul>
<li><strong><code>403</code></strong> — the model is not enabled for the key&#39;s project. Open the project&#39;s Resources in the Console and enable it.</li>
<li><strong><code>404</code></strong> — <code>/v1</code> is in the wrong place, or the tool appended <code>/chat/completions</code> to a base URL that already ended in it.</li>
<li><strong>The model picker is empty</strong> — Dify never lists models for you; add each one by hand. In n8n, an empty list usually means the key or base URL is wrong, since the dropdown is populated from <code>GET /v1/models</code>.</li>
<li><strong>Tools are never called</strong> — in Dify, <code>Function Call Type</code> is still <code>no_call</code>.</li>
