3:T443,<h3 id="200-with-empty-content">200 with empty content</h3>
<p>A request can return <code>200 OK</code> with an empty message — no error, just no text. This is almost always driven by request parameters, not a failure. The most common cause is a <code>max_tokens</code> that is too low for a reasoning (extended-thinking) model: the entire budget is consumed by internal reasoning before any visible output is produced, so the content comes back empty.</p>
<p>On this platform that request typically reports <strong>zero token usage and deducts no <a class="doc-term" href="/docs/credits" data-def="The billing unit. 1 USD = 100 credits; usage converts at each model's list rate.">credits</a></strong> — an empty <code>200</code> with an empty <code>usage</code> object is the signature of this case, not a billing bug. Fix it by raising <code>max_tokens</code> so it covers the model&#39;s thinking budget plus your expected output, or turn extended thinking off. Always check <code>finish_reason</code> / <code>stop_reason</code> and <code>usage</code> before assuming text
