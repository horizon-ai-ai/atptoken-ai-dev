Agent skills· 讓 AI 自己接上

讓你的 agent 自己接上 ATP

裝一次 ATP Skills，你的編碼代理就知道驗證方式、模型代號、payload 與非同步媒體流程——不必再向它解釋任何供應商 SDK。

在你的專案裡執行

curl -fsSL https://atptoken.ai/skills/install.sh | sh -s -- claude

Skills 只有 Markdown，不會帶著你的金鑰。
