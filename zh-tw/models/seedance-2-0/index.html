適合場景

適合
  • 一次生成、同時帶有音效的電影感短片
  • 以圖片與影片參考維持角色與場景一致的參考式生成
  • 以首尾幀鎖定畫面、控制轉場的鏡頭
  • 先用 Seedance 2.0 Fast 試 prompt，再出正式成片
通常較不適合
  • 快速、低成本的反覆試作——ATP 上的 Seedance 2.0 Fast 更快也更省
  • 超過 15 秒的單支連續影片——更長的作品需由多段影片組合

Seedance 2.0 可以輸入什麼、會產出什麼？
Seedance 2.0 是 ByteDance (Seedance) 的影片生成模型。輸入文字提示（可附圖片或影片），產出影片（480p / 720p / 1080p / 4k）。純文字和帶圖／影片的請求價格不同。
Seedance 2.0 怎麼計價？
按影片秒數計價，每秒價格看你選的解析度（480p / 720p / 1080p / 4k）。價格區也列出各解析度每百萬影片 Token 的價格。請求成功才扣點，失敗不收費。1 美元 = 100 點數。 查看價格
怎麼透過 ATP 呼叫 Seedance 2.0？
建立專案 API 金鑰，先用 GET https://api.atptoken.ai/v1/models 確認看得到「seedance-2-0」，再照影片生成文件發請求，model 填這個代號。
