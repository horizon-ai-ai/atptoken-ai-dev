常見問題

GPT Image 2 在 ATP Token 上多少錢？
GPT Image 2（API：gpt-image-2）的 USD 牌價為：每百萬 Token 文字輸入 5.00 美元、圖片輸出 30.00 美元。計費單位為點數（1 美元 = 100 點數），依完成請求自專案餘額扣款；無月費、最低儲值見定價頁。
如何用 API 呼叫 GPT Image 2？
簽發專案 API 金鑰，在專案白名單啟用代號 gpt-image-2（不是顯示名稱），將 OpenAI 相容 SDK 的 base_url 指向 https://api.atptoken.ai/v1，model 參數必須設為「gpt-image-2」。詳見本頁 Quickstart 與文件。
GPT Image 2 的上下文與能力？
深度思考、工具、視覺等能力旗標依閘道模型目錄回報，實際以你金鑰可見的目錄為準；上下文數字有可靠來源才會標示。供應商為 OpenAI。
誰可以呼叫 GPT Image 2？
僅專案允許清單中的模型代號可被該專案金鑰呼叫。組織／工作區／專案分層治理、逐請求紀錄與點數預算皆在 ATP Console 管理。
