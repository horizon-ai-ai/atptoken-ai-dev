The name· 名字的三層

Agent · Token · Petrichor

完整的名字是 Agent Token Petrichor。三個字，因為這個平台要同時回答三個問題：誰在花、用什麼計價、以及這件事為什麼重要。

縮寫不是巧合。生物學裡，ATP（三磷酸腺苷）是細胞的能量貨幣：無論能量從哪裡來，都得先換成 ATP，身體才用得上。算力也是同一個道理——它得先變成 token，企業才真正花得出去。而這道轉換、以及轉換的計量與帳，就是我們工作的那一層。

Agent誰在花

請求不再來自坐在鍵盤前的人，而是來自會自己迴圈、重試、呼叫工具的代理程式——這正是花費需要一套結構的原因：它不能靠某個人記得去看一眼。

Token用什麼計價

Token 是智慧真正的計價單位。每一筆請求都以它計量、歸屬到專案、以點數結算——成本不再是每月的意外，而是每一次呼叫都有的一個數字。

Petrichor為什麼重要

Petrichor 是雨後土地甦醒的氣息。新模型像那場雨一樣不斷落下，落在組織的每個角落。我們做的事，是把這場雨匯進渠道，而不是讓它積在沒人看的地方。
