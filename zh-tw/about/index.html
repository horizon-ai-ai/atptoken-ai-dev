Name· 名字的來源

名字是怎麼來的

完整的名字是 Agent Token Petrichor。​三個字裡有兩個在講平台怎麼運作——誰在花、​用什麼計價；​第三個字只是名字的來源。

  1. AAgent

    誰在花

    請求不再來自坐在鍵盤前的人，而是來自會自己迴圈、重試、呼叫工具的代理程式——這正是花費需要一套結構的原因：它不能靠某個人記得去看一眼。

  2. TToken

    用什麼計價

    文字模型按 Token 計量；其他模型依公開費率按圖片、秒或字元計費。ATP 將每筆用量歸屬到專案，並以點數結算。

  3. PPetrichor

    名字的來源

    Petrichor 是一個少用的英文字，語源來自希臘文（petra + ichor）。它在這裡只有一個作用：解釋名字怎麼來的——不是產品隱喻，也不構成品牌承諾。平台的承諾是白話的那一句——算力成為有歸屬、有帳的行動。完整名稱只留在法律實體與早期資料裡，產品名是 ATP Token。

縮寫不是巧合。生物學裡，ATP（三磷酸腺苷）是細胞的能量貨幣：無論能量從哪裡來，都得先換成 ATP，身體才用得上。算力也是同一個道理——它得先變成 token，企業才真正花得出去。而這道轉換、以及轉換的計量與帳，就是我們工作的那一層。
