<h2 id="openrouter-怎麼收費-截至-2026-年-10-月">OpenRouter 怎麼收費（截至 2026 年 10 月）</h2>
<p>OpenRouter 不在 token 價格上加價，官方說法是照供應商價格轉嫁，費用收在購買點數時（<a href="https://openrouter.ai/docs/faq" target="_blank" rel="noopener noreferrer">FAQ</a>）：</p>
<ul>
<li>Standard（按量付費）：刷卡 5.5%，最低 0.80 美元；加密貨幣 5%。</li>
<li>Business：8%。Enterprise：另議。</li>
<li>自帶供應商金鑰（BYOK）：Standard 與 Business 每月前 25,000 美元定價用量免費，超過收 5%。</li>
</ul>
<p>舉兩個例子。在 Standard 刷卡買 1,000 美元點數，實付 1,055 美元。買 10 美元則實付 10.80 美元，因為最低 0.80 美元高於 5.5%。</p>
<p>財務要注意兩條條款：OpenRouter 保留在購買一年後讓未使用點數失效的權利；未使用點數的退款必須在 24 小時內申請。開立發票（invoicing）只列在 Enterprise 方案。</p>
<h2 id="openrouter-已經能替團隊做的事">OpenRouter 已經能替團隊做的事</h2>
<p>有些比較文章（包括本文的舊版）把 OpenRouter 描述成沒有團隊控管的開發者錢包，這已經過時。</p>
<ul>
<li>組織共用一個點數池，只有管理員能購買點數、調整帳務、供應商與隱私設定。</li>
<li><a href="https://openrouter.ai/docs/guides/features/workspaces" target="_blank" rel="noopener noreferrer">工作區</a>可以把 API 金鑰、路由預設、guardrails 與觀測分開，例如分成測試與正式環境。</li>
<li><a href="https://openrouter.ai/docs/guides/features/guardrails" target="_blank" rel="noopener noreferrer">Guardrails</a> 可套在成員或金鑰上，組合按日、週、月重置的美元預算、模型白名單、供應商白名單、零資料保留規則，以及提示注入或個資過濾。多條同時適用時，以最嚴格的為準。</li>
<li>每把 API 金鑰都能設自己的點數上限，任何方案都可以。</li>
<li>所有方案都有活動紀錄與匯出，可依模型、金鑰或成員分組。</li>
<li>Claude Code 可以接 OpenRouter 的 Anthropic 相容端點（<a href="https://openrouter.ai/docs/guides/guides/claude-code-integration" target="_blank" rel="noopener noreferrer">設定說明</a>）。</li>
</ul>
<p>如果這些控管已經夠用，手續費也能接受，繼續用 OpenRouter 是合理的。</p>
<h2 id="團隊為什麼找替代方案">團隊為什麼找替代方案</h2>
<p>常見原因，每一條都對應文件上查得到的差異：</p>
<ol>
<li>閘道必須跑在公司網路內，或流量只能送到公司自己持有的供應商帳號。</li>
<li>財務希望預算綁在產品線或成本中心。OpenRouter 在 Enterprise 以下，預算掛在成員與金鑰上；工作區預算要 Enterprise。</li>
<li>財務希望用不會過期的預付點數，事先撥給每個專案。</li>
<li>部分應用用的是 Google GenAI SDK，團隊希望閘道直接接受這個格式，不必改寫。</li>
</ol>
<p>下面每個替代方案各自回應其中幾項。</p>
<h2 id="逐一看替代方案">逐一看替代方案</h2>
<h3 id="litellm-自架-proxy">LiteLLM：自架 proxy</h3>
<ul>
<li>適合：閘道必須放在自家雲端或 VPC，而且已經有供應商帳號的團隊。</li>
<li>費用：開源 proxy 免費；你直接付供應商帳單，加上維運成本。部分功能（例如使用者與金鑰層級的「依模型」預算）需要 Enterprise 授權。</li>
<li>控管：可依金鑰、使用者、團隊與客戶設預算，重置週期如 <code>30d</code>；模型權限用 access group 管理。</li>
<li>要注意：可用性、資料庫、升級與資安審查都歸你。Anthropic 的 Claude Code 文件提到有企業用 LiteLLM 依金鑰追蹤花費，也註明它與 Anthropic 無關、未經其稽核（<a href="https://code.claude.com/docs/en/costs" target="_blank" rel="noopener noreferrer">來源</a>）。</li>
</ul>
<h3 id="vercel-ai-gateway-代管-照供應商定價">Vercel AI Gateway：代管，照供應商定價</h3>
<ul>
<li>適合：已經部署在 Vercel 的團隊，或想要代管閘道、又不想在 token 上付平台費的人。</li>
<li>費用：token 不加價、不收平台費；可能有金流手續費；Enterprise 可開發票（<a href="https://vercel.com/docs/ai-gateway/pricing" target="_blank" rel="noopener noreferrer">定價</a>）。</li>
<li>控管：可對團隊、專案、API 金鑰或成員設預算，按日、週、月或不重置；超過回傳 HTTP 402；在 50%、75%、100% 寄信通知。</li>
<li>要注意：Vercel 自己說預算是軟上限，跨過上限的那一筆請求仍會完成。用自帶供應商金鑰的花費不計入預算。整個團隊層級的供應商白名單，每 1,000 筆請求收 0.10 美元。</li>
</ul>
<h3 id="atp-token-專案預付額度-每個專案自己的模型白名單">ATP Token：專案預付額度＋每個專案自己的模型白名單</h3>
<ul>
<li>適合：好幾個團隊共用一筆 AI 預算，財務希望每個專案先撥款、並只能用審核過的模型。</li>
<li>費用：依輸入與輸出 token、按各模型定價計量，從點數扣抵。1 點 = 0.01 美元，儲值 5 美元起，按量付費的點數不會過期（<a href="/zh-tw/docs/credits/" class="doc-term-def" data-def="計費單位。1 點＝USD 0.01；用量依各模型牌價換算成點數扣抵。">點數</a>、<a href="/zh-tw/docs/topup/" class="doc-term-def" data-def="為錢包加值點數，USD 5 起儲值，用多少付多少。">儲值</a>、<a href="/zh-tw/pricing/">定價</a>）。</li>
<li>控管：點數由組織往下撥到工作區、再到專案，專案只能花被撥到的額度，用完回傳 402。每個專案有允許的模型清單，呼叫清單外的模型會在送到供應商之前回傳 403（<a href="/zh-tw/docs/how-it-works/">運作方式</a>）。</li>
<li>格式：OpenAI、Anthropic、Google GenAI 官方 SDK 都能原樣使用，只換 base URL 與金鑰（<a href="/zh-tw/docs/sdk-openai/">OpenAI SDK</a>、<a href="/zh-tw/docs/sdk-google/">Google GenAI SDK</a>）。</li>
<li>要注意：模型目錄比 OpenRouter 小（11 家供應商、70+ 個模型，對比 500+）。點數不可退款。請求紀錄保留 7 天，月度檢討需要的資料請先匯出。</li>
</ul>
<p>Portkey 與 Helicone 也常出現在「OpenRouter 替代方案」清單裡，放在 <a href="/zh-tw/blog/ai-gateway-comparison-2026/">LLM 閘道比較</a>一起談。</p>

<h2 id="把-openrouter-整合搬到-atp-token">把 OpenRouter 整合搬到 ATP Token</h2>
<p>如果你的程式用 OpenAI SDK 呼叫 OpenRouter，搬家只要換 base URL、金鑰與模型 id。</p>
<ol>
<li>在主控台建立專案，勾選允許的模型，例如 <a href="/zh-tw/models/claude-sonnet-4-6/">claude-sonnet-4-6</a> 與 <a href="/zh-tw/models/deepseek-v4-flash/">deepseek-v4-flash</a>（<a href="/zh-tw/docs/resources/" class="doc-term-def" data-def="這個 專案 可以呼叫的模型清單；不在清單上的一律回 403。">工作區與專案</a>）。</li>
<li>撥點數給專案，這個金額就是它的上限（<a href="/zh-tw/docs/cb-budget-caps/">預算上限設定</a>）。</li>
<li>為專案建立金鑰，開頭是 <code>atp-</code>，只顯示一次（<a href="/zh-tw/docs/console-keys/" class="doc-term-def" data-def="以 atp- 開頭的金鑰，繼承所屬 專案 的允許模型清單與點數餘額。">管理金鑰</a>）。</li>
<li>改 client 與模型 id。OpenRouter 的 id 帶供應商前綴（<code>vendor/model</code>）；ATP 的 id 以 <code>GET /v1/models</code> 回傳的為準。</li>
</ol>
<pre><code>from openai import OpenAI

# 原本：OpenAI(base_url=&quot;https://openrouter.ai/api/v1&quot;, api_key=&quot;sk-or-...&quot;)
client = OpenAI(base_url=&quot;https://api.atptoken.ai/v1&quot;, api_key=&quot;atp-...&quot;)

r = client.chat.completions.create(
    model=&quot;claude-sonnet-4-6&quot;,
    messages=[{&quot;role&quot;: &quot;user&quot;, &quot;content&quot;: &quot;用兩行摘要這張工單。&quot;}],
)
print(r.choices[0].message.content)
</code></pre>
<ol start="5">
<li>送一筆測試請求，確認它出現在請求紀錄裡，並有輸入與輸出 token（<a href="/zh-tw/docs/monitoring/">用量與紀錄</a>）。</li>
</ol>
<p>Claude Code 也是同樣做法，設定四個環境變數即可（<a href="/zh-tw/docs/cb-claude-code/">在 ATP 上跑 Claude Code</a>）。</p>
