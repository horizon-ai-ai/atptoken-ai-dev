<p>先給答案：單價可跌、agent 帳單仍升，因為單位從「一次 completion」變成「一項完成的任務」。量測<strong>每次 agent 任務成本</strong>，設步數與預算天花板，保留逐請求紀錄。見<a href="/zh-tw/blog/why-ai-bills-explode-after-go-live">上線後帳單為何炸</a>、<a href="/zh-tw/blog/how-to-read-your-ai-bill">讀懂 AI 帳單</a>。</p>

<p>單輪聊天付一塊輸入與輸出；agent 可能每輪重讀逐字稿、吞工具結果、重試、複製上下文給子 agent。多出來的 token 即 agent tax——架構稅，不是供應商加價。</p>

<h2 id="常見問題">常見問題</h2>
<h3 id="什麼是-ai-的-agent-tax">什麼是 AI 的 agent tax？</h3>
<p>Agent tax 是多步 agent 因重送上下文、工具呼叫與重試，超出單次模型回覆的額外 token 支出。</p>
<h3 id="為什麼-ai-agent-比一般聊天更貴">為什麼 AI agent 比一般聊天更貴？</h3>
<p>Agent 可能為同一目標發起多次呼叫，每次帶歷史與工具結果，任務級 token 會倍增。</p>
<h3 id="怎麼量測-agent-tax">怎麼量測 agent tax？</h3>
<p>依任務彙總整條鏈路的 token 與點數，再與單輪基準比；用完成任務成本做共同語言。</p>
<h3 id="如何降低-agent-token-成本">如何降低 agent token 成本？</h3>
<p>限制步數、摘要上下文、子任務用小模型、專案上限，並每週查請求紀錄。</p>
<h3 id="agent-tax-等於模型加價嗎">Agent tax 等於模型加價嗎？</h3>
<p>不是。加價是費率差；agent tax 是架構讓同一費率消耗更多 token。</p>
