<h2 id="簡短回答">簡短回答</h2>
<p>只有一個團隊、只用 OpenAI 模型，而且 OpenAI 的專案上限已經符合你的預算規則，就直接用 OpenAI API。</p>
<p>出現下列任一情況，就該加一層 OpenAI 相容閘道：</p>
<ul>
<li>第二家供應商進來了，例如寫程式用 Claude、大量分類用 Gemini Flash，而財務希望只有一張帳單、一套上限。</li>
<li>好幾個團隊共用一筆 AI 預算，每個團隊都需要跨供應商的上限與模型清單。</li>
<li>想用自己的提示詞比較模型，又不想接三套 SDK。</li>
</ul>
<h2 id="openai-平台已經提供的控管">OpenAI 平台已經提供的控管</h2>
<p>單一供應商時，過去需要閘道才能做到的控管，OpenAI 大多已經自己做了：</p>
<ul>
<li>專案可以把測試與正式環境分開，各自有金鑰、速率上限與花費上限（<a href="https://developers.openai.com/api/docs/guides/production-best-practices" target="_blank" rel="noopener noreferrer">正式環境最佳實務</a>）。</li>
<li>兩種花費控管：花費提醒只發通知，流量照跑；硬性花費上限會讓受影響的請求回傳 429（<a href="https://developers.openai.com/api/docs/guides/rate-limits" target="_blank" rel="noopener noreferrer">速率上限說明</a>）。</li>
<li>專案層級的「Model usage」設定，限制專案可以呼叫哪些模型（<a href="https://help.openai.com/en/articles/9186755-managing-projects-in-the-api-platform" target="_blank" rel="noopener noreferrer">管理專案</a>）。</li>
<li>使用量等級（usage tier）會在付款累積到一定金額前限制每月花費，從 Tier 1 每月 100 美元到 Tier 5 每月 200,000 美元。</li>
</ul>
<p>如果流量全部是 OpenAI，先用好這些功能。</p>
<h2 id="直接串接的極限">直接串接的極限</h2>
<p>上面這些上限只管得到 OpenAI 的模型。團隊一加入 Claude，Anthropic 主控台就有另一套工作區、花費上限與金鑰（<a href="https://platform.claude.com/docs/en/manage-claude/workspaces" target="_blank" rel="noopener noreferrer">Anthropic 工作區</a>）。再加上 Gemini，就是第三個主控台。實際上會變成：</p>
<ul>
<li>有人離職時，要在三個地方發放與撤銷金鑰。</li>
<li>三套互相看不到的預算，「客服機器人每月跨所有供應商最多花 3,000 美元」這條規則沒有地方能執行。</li>
<li>月底收到三張格式不同的帳單。</li>
<li>程式碼分散在 OpenAI、Anthropic、Google 三套 SDK。</li>
</ul>
<p>閘道在它們前面放一套金鑰、上限與紀錄。</p>
<h2 id="程式要改哪裡">程式要改哪裡</h2>
<p>用 ATP Token 時 OpenAI SDK 照用，只改三個值（<a href="/zh-tw/docs/sdk-openai/">OpenAI SDK 說明</a>、<a href="/zh-tw/docs/cb-migrate-openai/">從 OpenAI 遷移</a>）：</p>
<pre><code>from openai import OpenAI

# 原本：client = OpenAI(api_key=&quot;sk-...&quot;)
client = OpenAI(base_url=&quot;https://api.atptoken.ai/v1&quot;, api_key=&quot;atp-...&quot;)

for model in [&quot;gpt-5.4&quot;, &quot;claude-sonnet-4-6&quot;, &quot;gemini-3-5-flash&quot;]:
    r = client.chat.completions.create(
        model=model,
        messages=[{&quot;role&quot;: &quot;user&quot;, &quot;content&quot;: &quot;請分類這張工單：「退款十天還沒收到」&quot;}],
        max_tokens=200,
    )
    print(model, r.choices[0].message.content, r.usage.total_tokens)
</code></pre>
<p>不變的部分：Chat Completions 的請求內容、回應內容、<code>stream=True</code> 的串流（<a href="/zh-tw/docs/sse-openai/">OpenAI SSE</a>），以及工具定義。</p>
<p>會變的部分：</p>
<ul>
<li>模型 id 以 <code>GET /v1/models</code> 回傳的為準（<a href="/zh-tw/docs/models/">模型查詢</a>）。OpenAI 模型沿用 <code>gpt-5.4</code> 這類熟悉的名稱；其他模型用 <code>claude-sonnet-4-6</code>、<code>deepseek-v4-flash</code> 這類 id。</li>
<li>不在專案允許清單上的模型，會在送到任何供應商之前回傳 403。</li>
<li>專案<a class="doc-term" href="/zh-tw/docs/credits/" data-def="計費單位。1 點＝USD 0.01；用量依各模型牌價換算成點數扣抵。">點數</a>用完時，請求回傳 402（<a href="/zh-tw/docs/errors/">錯誤</a>）。</li>
<li>ATP 的 OpenAI 格式端點是 <code>/v1/chat/completions</code>、<code>/v1/models</code> 與 <code>/v1/files</code>。程式若呼叫其他 OpenAI 端點，搬移前先查 <a href="/zh-tw/docs/chat/">API 參考</a>。</li>
</ul>
<p>使用 Anthropic 或 Google GenAI SDK 的團隊不必改成 OpenAI 格式：同一把專案金鑰也能在 <code>https://api.atptoken.ai</code> 搭配這兩套 SDK 使用（<a href="/zh-tw/docs/sdk-anthropic/">Anthropic SDK</a>、<a href="/zh-tw/docs/sdk-google/">Google GenAI SDK</a>）。</p>
<h2 id="同一個工作負載在六個模型上的花費">同一個工作負載在六個模型上的花費</h2>

<li>先在測試環境改 base URL、金鑰與模型 id，在請求紀錄裡比對輸出與 token 數（<a href="/zh-tw/docs/monitoring/">用量與紀錄</a>）。</li>
<li>正式環境一次搬一個服務，最後撤銷不再使用的 OpenAI 金鑰。</li>
