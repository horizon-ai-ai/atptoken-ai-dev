<h2 id="常見問題">常見問題</h2>
<h3 id="為什麼-coding-agent-在-api-計費下很貴">為什麼 coding agent 在 API 計費下很貴？</h3>
<p>反覆送 repo 上下文、多步工具與重試，使每次完成變更的 token 遠高於單次聊天。</p>
<h3 id="claude-code-可以跟正式服務共用-api-金鑰嗎">Claude Code 可以跟正式服務共用 API 金鑰嗎？</h3>
<p>不可以。應給 coding agent 獨立專案、金鑰、白名單與點數上限。</p>
<h3 id="如何為-coding-agent-設花費上限">如何為 coding agent 設花費上限？</h3>
<p>固定專案點數天花板、耗盡前告警、白名單限制 frontier，並在 agent 設定 max steps / max tokens。</p>
<h3 id="應追蹤哪些指標">應追蹤哪些指標？</h3>
<p>每次成功任務的點數、每任務請求數、輸入輸出 token、依模型排序的花費。</p>
<h3 id="如何經企業閘道跑-claude-code">如何經企業閘道跑 Claude Code？</h3>
<p>把 base URL 指到閘道、專案金鑰作 auth、清掉衝突的原廠環境變數，且只啟用該專案允許的模型。</p>
