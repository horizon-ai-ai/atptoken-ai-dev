3:Tb11,<h3 data-md="h3" id="要有一個真人登入" class="group">要有一個真人登入<a href="#要有一個真人登入" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p><code>POST /api/users/login</code> 的 body 必須帶人機驗證的答案，而只有瀏覽器產生得出來。主控台 API 沒有 API 金鑰、沒有服務帳號，也沒有給機器登入的端點：這幾頁上的每一個呼叫，用的都是某個真人在 <a href="https://atptoken.ai" target="_blank" rel="noopener noreferrer">atptoken.ai</a> 登入後拿到的 session token。</p>
<p>這是一個決定，不是還沒做完的功能。登入頁正是腳本猜密碼會打的地方，而原本唯一的防線——單一帳號的失敗次數上限——罰錯了人：腳本換下一個帳號繼續猜，被鎖在外面的卻是真正的持有人。人機驗證在第一個請求就擋下整輪，所以它對每一次登入都生效，沒有門檻可以跨過，也沒有例外可以申請。</p>
<p>在瀏覽器登入之後，主控台把那個 session token 放在 <code>localStorage</code> 的 <code>atp_token</code>——它就是以下範例裡的 <code>$TOKEN</code>。這是 Bearer token，效期約 <strong>2 小時</strong>，<code>POST /api/users/logout</code> 可以提前結束它。</p>
<h3 data-md="h3" id="這代表什麼事做不到" class="group">這代表什麼事做不到<a href="#這代表什麼事做不到" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>腳本不能自己登入，也就不能讓自己一直保持認證：token 過期之後，要有一個人重新登入。主控台 API 適合「手上有 session 時才跑」的工作——出報表、對帳、追一個失敗的請求——而不是一個長期無人看管的服務。</p>
<p>如果你要的是完全不需要 session 的花費上限，請改用<a class="doc-term" href="/zh-tw/docs/credits/" data-def="計費單位。1 點＝USD 0.01；用量依各模型牌價換算成點數扣抵。">點數</a>分配，而不是監看餘額：專案只能花掉被分配到的額度，而且是 Gateway 在每一個請求上執行。見<a href="/zh-tw/docs/cb-budget-caps/">建立帶預算上限的團隊</a>。</p>
<h2 data-md="h2" id="輪詢餘額-切換模型" class="group">輪詢餘額、切換模型<a href="#輪詢餘額-切換模型" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
