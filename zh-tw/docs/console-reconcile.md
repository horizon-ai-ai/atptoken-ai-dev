# 從一筆請求到月底對帳

> Source: https://atptoken.ai/zh-tw/docs/console-reconcile/

用主控台把一筆請求一路追到帳單：請求紀錄、點數扣款明細、可用天數，以及月底對帳 CSV。

## 開始之前

- 一把已經送出過請求的專案 API 金鑰。還沒有的話，先照[快速開始](https://atptoken.ai/zh-tw/docs/quickstart/)做。
- 你要追的那筆請求的 request ID。每個回應的 `x-request-id` 標頭都帶著它，回應 body 裡的 `id` 也是同一個值。
- 這四個畫面都在主控台左欄的「用量」底下，是同一頁的分頁：用量、請求紀錄、點數扣款明細、對帳。用量頁頂端的工作區與專案篩選決定所有分頁的範圍。

## 1. 在請求紀錄找到這一筆

開「用量」→「請求紀錄」。主控台總覽「最近請求」旁的「查看全部」也會開到這個分頁。

可依時間範圍（預設最近 24 小時；紀錄保留 7 天）、「狀態」、「模型」或「Request ID」篩選——貼上完整的 Request ID。條件一改就立即套用。

| 欄位 | 顯示什麼 |
|---|---|
| Request ID | 這筆請求的 request ID，旁邊有複製鈕；聯絡支援時附上它 |
| 時間 | 依你的當地時區顯示 |
| 模型 | 這筆請求呼叫的模型 ID |
| 呼叫身分 | 以金鑰呼叫時顯示金鑰標籤；從工作台發出的呼叫顯示登入者 |
| 狀態 | HTTP 狀態碼；400 以上會連到[錯誤碼](https://atptoken.ai/zh-tw/docs/errors/)裡對應的那一列 |
| 點數 | 這筆請求扣的點數，或它的扣款狀態 |
| 請求用量 | 這筆請求回報的用量 |

寬螢幕另外顯示「模態」與「端點」欄。同一個媒體任務的多次輪詢會收成一列，可以展開。

> **請求紀錄不是扣款依據**
>
> 請求紀錄用來排查 API，保留 7 天，不作為最終扣款依據。帳務請看點數扣款明細與對帳。

## 2. 在點數扣款明細確認扣款

請求紀錄的「點數」欄已經會顯示扣款狀態。要看某個帳單月份的扣款明細，開「用量」→「點數扣款明細」。

| 狀態 | `billing_status` | 「點數」欄顯示 |
|---|---|---|
| 已扣款 | `billed` | 扣掉的點數，到小數 4 位 |
| 結算中 | `pending` | 結算中 |
| 未扣款 | `unbilled` | 未扣款 |
| 不收費 | `not_billable` | 不收費；狀態碼 400 以上且 0 點的請求，請求紀錄也顯示不收費 |

點數扣款明細的欄位是 Request ID、時間、模型、模態、計費用量、狀態、點數，可依帳單月份、模態與狀態篩選。用 Request ID 就能和請求紀錄對上同一筆。

列表僅含你本人的活動（你的金鑰與你的主控台身份）；上方的本期合計是整個範圍的全量。這裡的帳單月份以 UTC 計。

## 3. 看用量與可用天數

「用量」→「用量」顯示所選範圍的用量與消耗；「匯出 CSV」下載 UTC 月份的 `usage-{period}.csv`。

主控台總覽的「今天」一列有「可用天數」：照最近的消耗速度，可用點數還能撐幾天。

- 可用天數＝（可用餘額 − 未結算保留）÷ 你本人金鑰的日均消耗，無條件捨去。
- 日均取今天以前最多 7 個完整 UTC 日，不含今天。
- 完整日不足 3 天時，卡片顯示需滿 3 個完整日，不顯示天數。
- 可用天數低於 7 天、而且沒有自動儲值在顧時，總覽會出現提醒並寫出剩幾天。

團隊組織的可用天數，是用組織餘額除以你本人金鑰的日均。

## 4. 匯出月底對帳 CSV

開「用量」→「對帳」，選月份。月份以台灣時間（UTC+8）計，可選最近 15 個月。

表格把計費帳本的小時資料按「台灣日 × 模型 × 模態」加總，欄位是日期（台灣）、模型、模態、請求數、點數。同一天有多列時收成「當日小計」，上方卡片是本月各模態合計。金額單位是點數。

「匯出 CSV」下載 `atp-reconcile-{YYYY-MM}.csv`；選了專案時檔名結尾加 `-project`，只選工作區時加 `-workspace`。

```text
date,model,modality,requests,credits_charged
YYYY-MM-DD,"<model>",<modality>,<requests>,<credits>
YYYY-MM TOTAL,,,<requests>,<credits>
```

CSV 的點數到小數 6 位。檔案是帶 BOM 的 UTF-8、CRLF 換行，用 Excel 開繁體中文不會亂碼。

> **結算前請再確認**
>
> 還有媒體任務未落帳時，對帳會顯示尚有幾筆——總額仍可能變動。

## 確認成功

- 回應裡的 Request ID 在請求紀錄與點數扣款明細都找得到。
- CSV 的 `TOTAL` 列等於對帳分頁的「本月合計」。
- 對帳是你本人的用量（你的金鑰＋主控台身份）；整個組織的月合計看點數扣款明細的本期合計。
- 點數扣款明細與用量 CSV 用 UTC 月份，對帳用台灣月份。台灣月份的前 8 小時落在上一個 UTC 月，所以兩邊的月合計在月界附近可能不同。
