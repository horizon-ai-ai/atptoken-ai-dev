# 團隊與角色

> Source: https://atptoken.ai/zh-tw/docs/team/

Team 組織可以加人，並在工作區或專案（project）層級指派角色。

## 角色

共有三種角色：

| 角色 | 可以做什麼 |
|---|---|
| Owner | 完整控制權。在 UI 中為唯讀，且無法被移除。 |
| Admin | 管理成員、資源、金鑰與點數分配。 |
| Member | 讀取並使用自己有權限的部分。 |

## 加入成員

**以 email 邀請** 會寄出一封需對方接受的邀請；**加入既有使用者** 則會立即掛上一個已存在的帳號。Personal 組織沒有團隊，會顯示一段說明取代成員面板。
