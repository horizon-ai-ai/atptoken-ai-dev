# 團隊與角色

> Source: https://atptoken.ai/zh-tw/docs/team/

Team organization 可以加人，並在 workspace 或 project 層級指派角色。共有三種角色：

| 角色 | 可以做什麼 |
|---|---|
| Owner | 完整控制權。在 UI 中為唯讀，且無法被移除。 |
| Admin | 管理成員、資源、key 與 credit 分配。 |
| Member | 讀取並使用自己有權限的部分。 |

**以 email 邀請** 會寄出一封需對方接受的邀請；**加入既有使用者** 則會立即掛上一個已存在的帳號。Personal organization 沒有團隊，會顯示一段說明取代成員面板。
