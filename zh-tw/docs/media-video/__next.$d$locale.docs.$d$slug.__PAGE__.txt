<h3 data-md="h3" id="欄位寫錯不會報錯" class="group">欄位寫錯不會報錯<a href="#欄位寫錯不會報錯" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p><code>content[]</code> 系列<strong>不檢查欄位名</strong>。拼錯的欄位、或這個模型不吃的欄位，一樣回 <code>202</code>，只是沒有效果。Kling、Seedance 沒宣告的頂層欄位會原樣轉給模型（例如 <code>negative_prompt</code>）；放進 <code>input: {…}</code> 的欄位也會轉送，而且同名時 <code>input</code> 裡的優先。</p>
<p>要確認參數有沒有生效，看輪詢結果裡的 <code>resolved_params</code>（模型實際採用的參數）；<code>params_raw</code> 是 gateway 實際送出的內容。<code>resolved_params</code> 也包含模型自己填的預設值，所以要比對<strong>值</strong>是不是你送的，不是只看欄位在不在。</p>
<p>扁平系列相反：多餘的欄位會被拒絕，回 <code>400 Extra inputs are not permitted</code>。</p>
<h2 data-md="h2" id="素材怎麼傳" class="group">素材怎麼傳<a href="#素材怎麼傳" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<p><code>content[].image_url.url</code>（或 <code>video_url.url</code>、<code>audio_url.url</code>）可以放：</p>4:Ta52,<p>這條鏈最常出錯的地方：</p>
<ul>
<li><strong>順序不能跳。</strong> 沒有 <code>group_id</code> 不能登記。素材還沒就緒就建任務，回 <code>400</code>（<code>reason: asset_not_ready</code>）；素材建立失敗，回 <code>400</code>（<code>reason: asset_failed</code>）。所以第三步的輪詢不能省。</li>
<li><strong><code>asset_type</code> 一定要寫</strong>，值是 <code>Image</code>、<code>Video</code>、<code>Audio</code>。不寫的話，影片可能被登記成圖片，而且不會報錯。</li>
<li><strong>建群組時帶 <code>model</code>。</strong> 帶了才保證這個群組之後能給那個模型用。</li>
<li><strong>群組有配額（約 50 個）。</strong> 重複使用群組，不要一個素材開一個。</li>
<li><strong><code>name</code> 最多 64 個字元。</strong> 超過時登記照樣回 200，輪詢才看到失敗（<code>InvalidParameter.Name</code>），拿它建任務會得到 <code>ATP_ASSET_FAILED</code>。縮短名字即可。</li>
<li><strong>同一個任務不能混用不同來源的素材</strong>，會回 <code>400</code>。</li>
<li>狀態變成 <code>Completed</code> 或 <code>Active</code>（依上游而定）才算就緒。</li>
</ul>
<p><strong>部分模型的登記是排隊的。</strong> 每個群組每 20 秒只建立一筆，所以會立刻回一個 <code>asset-q-…</code> 的 id（<code>AssetUri</code> 是 <code>asset://asset-q-…</code>）、狀態 <code>Processing</code>，並用 <code>Retry-After</code> 給出預估秒數。輪詢到 <code>Completed</code> 再拿去建任務。不同群組各自排隊。</p>
<p>素材跟群組同壽命：群組被清理後（影片完成後回收，或每天清掉閒置超過一天的群組），這個 id 就查不到了。</p>
<p><code>seedance-2-0-fast</code> 不接受素材，回 <code>422 this asset&#39;s upstream does not serve the requested model</code>，請直接傳公開網址。各 Seedance 模型的支援情況見 <a href="/zh-tw/docs/seedance-2-0/">Seedance</a>。</p>
<h3 data-md="h3" id="真人照片" class="group">真人照片<a href="#真人照片" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>真人照片用公開網址送出時，可能被拒，回 <code>400 may contain real person</code>。被擋時，把同一張圖登記成素材，改傳 <code>AssetUri</code>，<strong>不需要核身</strong>。<code>seedance-2-0-fast</code> 不能用素材，所以真人照片不要用它。</p>
<p>只有你的產品要求核身時，才走核身流程：</p>5:T66e,<p><strong>輸出跟著原片，不照 standard／pro 的 720p／1080p 規則。</strong> 給一支 1280×720、3 秒的原片：<code>-video-edit</code> 輸出 1280×720、3 秒（pro 也一樣）；<code>-v2v</code> 不送 <code>duration</code> 時輸出 1280×720、5 秒。</p>
<p><strong>prompt 第一句寫要改什麼。</strong> 點名目標、說出新狀態，保留只用一句帶過。逐項列出要保留的東西，或要求新主體符合舊主體的外觀，模型可能判斷成「什麼都不改」：任務照樣 <code>succeeded</code>，回來的還是原片。<code>succeeded</code> 不代表修改生效，要看回來的影片。</p>
<p>這兩類寫錯時在建立就被拒，不建立任務、不收費：</p>
<ul>
<li>影片放在 <code>content[]</code>（不論 <code>role</code> 是 <code>source_video</code> 還是 <code>reference_video</code>）→ <code>422 The parameter combination is not supported.</code></li>
<li>參考圖的 <code>role</code> 寫成 <code>reference_image</code> 或 <code>image</code> → 同上。這裡要寫 <code>reference</code>。</li>
</ul>
<h2 data-md="h2" id="阿里影片模型" class="group">阿里影片模型<a href="#阿里影片模型" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<p><code>wan-2-7-t2v</code>／<code>wan-2-7-i2v</code> 與 HappyHorse 的文生／圖生／參考圖模型用同一個端點與 <code>content[]</code> 寫法，以下只列各模型特有之處。<strong><code>happyhorse-1.0-video-edit</code> 是例外：它用另一個端點</strong>（見下）。</p>6:T9b3,<ul>
<li><code>input.media[].type</code> 只接受 <code>video</code> 與 <code>reference_image</code>，網址欄位名為 <code>url</code>（不是 <code>video_url</code>）。</li>
<li><strong>寫錯時建立仍回 <code>202</code></strong>，錯誤要等輪詢才以 <code>InvalidParameter</code> 出現，例如 <code>InvalidParameter: Field required: input.media</code>。建立成功不代表內容正確。</li>
<li>來源影片與每一張參考圖都必須能免登入直接下載；任一個抓不到時任務會以 <code>FAILED</code>＋<code>Failed to download …</code> 結束且不計費。</li>
<li>這個端點回自己的格式（<code>output.task_status</code>、<code>output.video_url</code>）；過期後是 <code>SUCCEEDED</code> + <code>video_url: null</code>。輸出長度依來源影片，不是 <code>parameters.duration</code>。</li>
<li>這個模型也可能在建立時回 <code>404 not_found_error — upstream returned 404</code>，意思同上：暫時無法服務，不收費。</li>
<li>權限、餘額與計費規則跟統一端點完全相同。</li>
</ul>
