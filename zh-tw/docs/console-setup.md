# 設定你的組織

> Source: https://atptoken.ai/zh-tw/docs/console-setup/

主控台裡的一切都掛在一個四層結構下。你只會建立一次組織，然後在裡面層層放進工作區、專案（project）與金鑰。

## 四個層級

| 層級 | 裝什麼 |
|---|---|
| 組織 | 帳單與團隊的邊界。分 Personal 或 Team。 |
| 工作區 | 一個點數容器，把相關的專案分在一起。 |
| 專案 | 設定允許的模型清單，並持有一份點數餘額。 |
| API 金鑰 | 範圍受限的憑證，繼承所屬專案的模型與點數。 |

## 建立組織

首次登入時，onboarding 會請你輸入組織名稱（會自動產生一個選填的小寫 slug）。**Team** 組織可以邀請成員並指派角色；**Personal** 組織為單人使用，並會隱藏 Team 頁。

## 下一步

- [工作區與專案](https://atptoken.ai/zh-tw/docs/resources/) — 建立工作區與專案，並把點數分配下去。
- [管理 API 金鑰](https://atptoken.ai/zh-tw/docs/console-keys/) — 建立只屬於一個專案的金鑰。
- [團隊與角色](https://atptoken.ai/zh-tw/docs/team/) — 邀請成員加入 Team 組織並指派角色。
