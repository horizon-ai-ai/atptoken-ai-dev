# 用量與紀錄

> Source: https://atptoken.ai/zh-tw/docs/monitoring/

有三個地方告訴你發生了什麼、花了多少：

### Usage
Credit 摘要（Available、Received、Consumed）、當月熱門模型，以及每把 key 的 token 總量。
### Request logs
每筆請求的稽核軌跡。可依時間範圍、範圍、模型、狀態或 request ID 篩選；欄位顯示狀態與 input / output tokens。
### Activity
安全與管理事件 — 登入、邀請、額度變更與資源更新。

時間戳記依你的本地時區顯示。Token 數為原始總數，不是 per-million。
