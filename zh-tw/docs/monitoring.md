# 用量與紀錄

> Source: https://atptoken.ai/zh-tw/docs/monitoring/

有三個地方告訴你發生了什麼、花了多少。

## 去哪裡看

### 用量
點數摘要（可用、已收到、已用）、當月熱門模型，以及每把金鑰的 token 總量。
### 請求紀錄
每筆請求的稽核軌跡。可依時間範圍、範圍、模型、狀態或 request ID 篩選；欄位依序是時間、模型、模態、端點、呼叫身分、狀態與點數。
### 活動紀錄
安全與管理事件——登入、邀請、額度變更與資源更新。

## 怎麼讀這些數字

時間戳記依你的本地時區顯示。Token 數為原始總數，不是 per-million。
