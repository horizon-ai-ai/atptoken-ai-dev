<p>不用。Gateway 相容 OpenAI、Anthropic 與 Google GenAI SDK — 把它們指向 Gateway base URL 並用 <a class="doc-term" href="/zh-tw/docs/console-keys/" data-def="以 atp- 開頭的金鑰，繼承所屬 project 的允許模型清單與點數餘額。">project API key</a> 即可。見 <a href="/zh-tw/docs/agents/">Integrations</a>。</p>
<h2 data-md="h3" id="base-url-是什麼">base URL 是什麼？</h2>
<p>Anthropic 與 Gemini 格式用 <code>https://api.atptoken.ai</code>,OpenAI 格式用 <code>https://api.atptoken.ai/v1</code>。各 SDK 頁會列出確切值。</p>
<h2 data-md="h3" id="我的-key-能呼叫哪些模型">我的 key 能呼叫哪些模型？</h2>
<p>只有它所屬 <a class="doc-term" href="/zh-tw/docs/resources/" data-def="權限與帳務的最小單位；金鑰、允許模型、點數預算都掛在 project 上。">project</a> 的 allowed list 上的模型。<a href="/zh-tw/docs/models/">GET /v1/models</a> 列出平台提供的清單；存取權在 request time 依 project 強制檢查 — 所以清單是選單，不是 key 的權限。</p>
<h2 data-md="h3" id="可以串流回應嗎">可以串流回應嗎？</h2>
<p>可以。設 <code>stream: true</code>,Gateway 會以對應你 SDK 的格式串流 SSE。見 <a href="/zh-tw/docs/sse-openai/">OpenAI SSE</a> 與 <a href="/zh-tw/docs/sse-anthropic/">Anthropic SSE</a>。</p>
<h2 data-md="h3" id="某個-provider-掛掉會怎樣">某個 provider 掛掉會怎樣？</h2>
<p>每個模型由一個 provider pool 服務，Gateway 會自動 fail over。若某模型的所有 provider 都不可用，你會收到帶 <code>Retry-After</code> 的 <code>503</code>。見 <a href="/zh-tw/docs/provider-routing/">Provider routing</a>。</p>
<h2 data-md="h3" id="怎麼計費-credits-可以退款嗎">怎麼計費？credits 可以退款嗎？</h2>
<p>用量以 input + output tokens 計量，並以 <a class="doc-term" href="/zh-tw/docs/credits/" data-def="計費單位。1 美元 = 100 點；用量依各模型牌價換算成點數扣抵。">credits</a> 支付(1 credit = USD 0.01)。<a class="doc-term" href="/zh-tw/docs/topup/" data-def="為錢包加值點數，最低 5 美元，用多少付多少。">儲值</a>與 credits 皆不可退款。見 <a href="/zh-tw/docs/credits/">點數如何運作</a> 與 <a href="/zh-tw/docs/topup/">儲值與錢包</a>。</p>
<h2 data-md="h3" id="我怎麼看花了多少">我怎麼看花了多少？</h2>
<p>Usage 頁依模型與 key 彙整 credits 與 tokens；request logs 提供每筆請求的稽核軌跡。見 <a href="/zh-tw/docs/monitoring/">用量與紀錄</a> 與 <a href="/zh-tw/docs/spend/">追蹤消耗</a>。</p>
<h2 data-md="h3" id="為什麼-reasoning-模型回傳-200-但內容是空的">為什麼 reasoning 模型回傳 200 但內容是空的？</h2>
<p><code>max_tokens</code> 設太低了。reasoning(extended thinking)模型的思考會吃同一個額度；額度在產生可見輸出前就用完，你會拿到空的 <code>200</code>——通常用量為零、也不會扣 credits。把 <code>max_tokens</code> 調高到「思考+預期輸出」都夠用。見<a href="/zh-tw/docs/errors/">常見回應</a>。</p>
