<h2 data-md="h2" id="連接-gateway" class="group">連接 Gateway<a href="#連接-gateway" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<h3 data-md="h3" id="我需要特別的-sdk-嗎" class="group">我需要特別的 SDK 嗎？<a href="#我需要特別的-sdk-嗎" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>不用。Gateway 相容 OpenAI、Anthropic 與 Google GenAI SDK——把它們指向 Gateway base URL 並用<a class="doc-term" href="/zh-tw/docs/resources/" data-def="權限與帳務的最小單位；金鑰、允許模型、點數預算都掛在 專案 上。">專案</a>（project） <a class="doc-term" href="/zh-tw/docs/console-keys/" data-def="以 atp- 開頭的金鑰，繼承所屬 專案 的允許模型清單與點數餘額。">API 金鑰</a>即可。見 <a href="/zh-tw/docs/agents/">Integrations</a>。</p>
<h3 data-md="h3" id="base-url-是什麼" class="group">base URL 是什麼？<a href="#base-url-是什麼" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>Anthropic 與 Gemini 格式用 <code>https://api.atptoken.ai</code>,OpenAI 格式用 <code>https://api.atptoken.ai/v1</code>。各 SDK 頁會列出確切值。</p>
<h3 data-md="h3" id="可以串流回應嗎" class="group">可以串流回應嗎？<a href="#可以串流回應嗎" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>可以。設 <code>stream: true</code>,Gateway 會以對應你 SDK 的格式串流 SSE。見 <a href="/zh-tw/docs/sse-openai/">OpenAI SSE</a> 與 <a href="/zh-tw/docs/sse-anthropic/">Anthropic SSE</a>。</p>
<h2 data-md="h2" id="模型與可用性" class="group">模型與可用性<a href="#模型與可用性" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<h3 data-md="h3" id="我的金鑰能呼叫哪些模型" class="group">我的金鑰能呼叫哪些模型？<a href="#我的金鑰能呼叫哪些模型" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>只有它所屬專案的 allowed list 上的模型。<a href="/zh-tw/docs/models/">GET /v1/models</a> 列出平台提供的清單；存取權在 request time 依專案強制檢查——所以清單是選單，不是金鑰的權限。</p>
<h3 data-md="h3" id="某個供應商掛掉會怎樣" class="group">某個供應商掛掉會怎樣？<a href="#某個供應商掛掉會怎樣" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>每個模型由一個供應商池 服務，Gateway 會自動切換。若某模型的所有供應商都不可用，你會收到帶 <code>Retry-After</code> 的 <code>503</code>。見 <a href="/zh-tw/docs/provider-routing/">供應商路由與備援</a>。</p>
<h3 data-md="h3" id="為什麼-reasoning-模型回傳-200-但內容是空的" class="group">為什麼 reasoning 模型回傳 200 但內容是空的？<a href="#為什麼-reasoning-模型回傳-200-但內容是空的" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p><code>max_tokens</code> 設太低了。推理模型（extended thinking）的思考會吃同一個額度；額度在產生可見輸出前就用完，你會拿到空的 <code>200</code>——通常用量為零、也不會扣<a class="doc-term" href="/zh-tw/docs/credits/" data-def="計費單位。1 點＝USD 0.01；用量依各模型牌價換算成點數扣抵。">點數</a>。把 <code>max_tokens</code> 調高到「思考+預期輸出」都夠用。見<a href="/zh-tw/docs/errors/">常見回應</a>。</p>
<h3 data-md="h3" id="atp-token-只有文字模型嗎" class="group">ATP Token 只有文字模型嗎？<a href="#atp-token-只有文字模型嗎" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>不是。目錄還包含圖像、影片、語音(TTS)與 embedding 模型。各模態的用途與計費方式見<a href="/zh-tw/docs/media/">媒體模型</a>。</p>
<h2 data-md="h2" id="計費與用量" class="group">計費與用量<a href="#計費與用量" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<h3 data-md="h3" id="怎麼計費-點數可以退款嗎" class="group">怎麼計費？點數可以退款嗎？<a href="#怎麼計費-點數可以退款嗎" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
<p>用量以 input + output tokens 計量，並以點數支付(1 點數 = USD 0.01)。<a class="doc-term" href="/zh-tw/docs/topup/" data-def="為錢包加值點數，USD 5 起儲值，用多少付多少。">儲值</a>與點數皆不可退款。見 <a href="/zh-tw/docs/credits/">點數如何運作</a> 與 <a href="/zh-tw/docs/topup/">儲值與錢包</a>。</p>
<h3 data-md="h3" id="我怎麼看花了多少" class="group">我怎麼看花了多少？<a href="#我怎麼看花了多少" aria-label="此段連結" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h3>
