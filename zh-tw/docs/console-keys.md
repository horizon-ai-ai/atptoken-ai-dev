# 管理 API keys

> Source: https://atptoken.ai/zh-tw/docs/console-keys/

Create key 精靈會帶你完成：命名 key、選擇（或建立）workspace 與 project，並可選擇順便撥一筆起始 credits。一把 key 一律只屬於一個 project，並繼承該 project 的模型與 credit balance。

> **完整密鑰只會顯示一次**
>
> key 以 `atp-` 開頭、長度 92 個字元。完整密鑰只會在建立當下顯示一次 — 請複製並妥善保存。之後只看得到 prefix。

**API keys** 頁列出這個 organization 底下、跨所有 workspace 與 project 的每一把 key。可依名稱或 prefix 搜尋、依 workspace 篩選，並隨時撤銷某把 key — 撤銷後該 key 會立即失效，但仍會留在名冊中供稽核。

以 project 為範圍的 key 才能把花費與存取歸帳。操作模式見 [一專案一金鑰](https://atptoken.ai/zh-tw/blog/one-project-one-key/)。
