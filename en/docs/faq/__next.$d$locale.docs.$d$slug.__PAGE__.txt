<p>No. The Gateway is compatible with the OpenAI, Anthropic, and Google GenAI SDKs — point them at the Gateway base URL and use a <a class="doc-term" href="/docs/console-keys" data-def="A key that starts with atp-. It inherits its project's allowed models and credit balance.">project API key</a>. See <a href="/docs/agents">Integrations</a>.</p>
<h3 id="what-is-the-base-url">What is the base URL?</h3>
<p><code>https://api.atptoken.ai</code> for the Anthropic and Gemini formats, and <code>https://api.atptoken.ai/v1</code> for the OpenAI format. Each SDK page shows the exact value.</p>
<h3 id="which-models-can-my-key-call">Which models can my key call?</h3>
<p>Only the models on its <a class="doc-term" href="/docs/resources" data-def="The unit that permissions and billing hang off — keys, allowed models, and credit budget all belong to one.">project</a>&#39;s allowed list. <a href="/docs/models">GET /v1/models</a> lists what the platform offers; access is enforced per project at request time, so the list is the menu — not your key&#39;s permissions.</p>
<h3 id="can-i-stream-responses">Can I stream responses?</h3>
<p>Yes. Set <code>stream: true</code> and the Gateway streams SSE in the format matching your SDK. See <a href="/docs/sse-openai">OpenAI SSE</a> and <a href="/docs/sse-anthropic">Anthropic SSE</a>.</p>
<h3 id="what-happens-if-a-provider-is-down">What happens if a provider is down?</h3>
<p>Each model is served by a pool of providers and the Gateway fails over automatically. If every provider for a model is unavailable you get a <code>503</code> with <code>Retry-After</code>. See <a href="/docs/provider-routing">Provider routing</a>.</p>
<h3 id="how-am-i-billed-and-are-credits-refundable">How am I billed, and are credits refundable?</h3>
<p>Usage is metered on input + output tokens and paid in <a class="doc-term" href="/docs/credits" data-def="The billing unit. 1 USD = 100 credits; usage converts at each model's list rate.">credits</a> (1 credit = USD 0.01). <a class="doc-term" href="/docs/topup" data-def="Adding credits to the wallet. Minimum 5 USD, pay as you go.">Top-ups</a> and credits are non-refundable. See <a href="/docs/credits">How credits work</a> and <a href="/docs/topup">Top up &amp; wallet</a>.</p>
<h3 id="how-do-i-see-what-i-spent">How do I see what I spent?</h3>
<p>The Usage page summarizes credits and tokens by model and by key; request logs give a per-request audit trail. See <a href="/docs/monitoring">Usage &amp; logs</a> and <a href="/docs/spend">Tracking spend</a>.</p>
<h3 id="why-did-a-reasoning-model-return-200-with-an-empty-message">Why did a reasoning model return 200 with an empty message?</h3>
<p><code>max_tokens</code> was too low. Reasoning (extended-thinking) models spend their thinking inside that budget; when it runs out before any visible output, you get an empty <code>200</code> — typically with zero usage and no credits deducted. Raise <code>max_tokens</code> to cover thinking plus your expected output. See <a href="/docs/errors">Common responses</a>.</p>
<h3 id="does-atp-token-only-serve-text-models">Does ATP Token only serve text models?</h3>
<p>No. The catalog also includes image, video, audio (TTS) and embedding models. See <a href="/docs/media">Media models</a> for what each modality does and how it is
