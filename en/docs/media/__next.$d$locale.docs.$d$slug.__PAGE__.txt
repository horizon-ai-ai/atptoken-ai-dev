3:T4d0,<h2 data-md="h2" id="check-which-models-you-can-use" class="group">Check which models you can use<a href="#check-which-models-you-can-use" aria-label="Link to this section" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<p>Call <code>GET https://api.atptoken.ai/v1/project/models</code> with your key. It is the project&#39;s complete list: text, image, video, audio and embedding models together. <code>GET /v1/models</code> lists only OpenAI-dialect chat models; media models are not on it. A model missing from a list is not necessarily unusable; without permission, create returns <code>403</code> and nothing is billed.</p>
<h2 data-md="h2" id="image-video-and-audio-are-all-asynchronous" class="group">Image, video and audio are all asynchronous<a href="#image-video-and-audio-are-all-asynchronous" aria-label="Link to this section" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<p>None of the three media surfaces has a synchronous variant. The flow is the same: create a task → poll until terminal → download before the signed URL expires. <strong>Only the result field differs:</strong></p>4:T525,<ul>
<li>Statuses are <code>queued</code>, <code>running</code>, <code>succeeded</code>, <code>failed</code>, <code>expired</code> and <code>cancelled</code>; the last four are terminal.</li>
<li><strong>Signed URLs expire after 24 hours.</strong> After that the status is still <code>succeeded</code>, but the URL is <code>null</code> and <code>expired: true</code> appears.</li>
<li>There are no webhooks; <code>callback_url</code> is never used, so you must poll.</li>
<li>Use a separate <code>Idempotency-Key</code> per media surface; reusing one across two surfaces returns <code>409</code>.</li>
</ul>
<h2 data-md="h2" id="video" class="group">Video<a href="#video" aria-label="Link to this section" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<p>Video models include the Seedance family (<code>seedance-2-0</code>, <code>-fast</code>, <code>-mini</code>, <code>seedance-2-5</code>) plus the Kling, Wan, HappyHorse and MiniMax families. Request shapes differ by family; see <a href="/docs/media-video/">Video generation</a> for the full list and how to call each. Per-model rates are on the <a href="/pricing/">pricing page</a>.</p>
<p>Video generation bills on <strong>video tokens</strong>, settled on actual usage once the task finishes:</p>5:T930,<p>Worth knowing before you render:</p>
<ul>
<li><strong>Aspect ratio changes the price.</strong> Cost follows actual width × height — a 1:1 clip at 720p costs ~44% less than 16:9 at the same tier.</li>
<li><strong>When the model picks the duration, you pay for the seconds it actually renders</strong>, not the number in the request.</li>
<li><strong>Reference video switches tiers.</strong> Adding input video moves the task to the with-input rate, and input seconds enter the formula.</li>
<li><strong>Available resolutions depend on the model</strong>; see each family in <a href="/docs/media-video/">Video generation</a>, and the <a href="/pricing/">pricing page</a> for rates.</li>
<li><strong>An exhausted balance returns <code>402</code> at create.</strong> If the balance is short at settlement it goes negative and the next request is blocked.</li>
<li><strong>Failed tasks are not billed.</strong></li>
</ul>
<p>For Seedance parameters and examples, see <a href="/docs/seedance-2-0/">Seedance</a>.</p>
<h2 data-md="h2" id="image" class="group">Image<a href="#image" aria-label="Link to this section" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<p>Text-to-image is an asynchronous task too: create it, poll, and read the result from <code>data[].url</code>. List pricing will be published at launch; the model appears on the pricing page as <strong>Preview</strong> until then.</p>
<h2 data-md="h2" id="audio-text-to-speech" class="group">Audio (text-to-speech)<a href="#audio-text-to-speech" aria-label="Link to this section" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<p>TTS is an asynchronous task; the result is in <code>audio_url</code>. It bills <strong>per character</strong> of input text rather than per token. List pricing will be published at launch.</p>
