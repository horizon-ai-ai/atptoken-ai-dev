25:T760,<p>If you send OpenAI&#39;s <code>role: &quot;tool&quot;</code> here, the Gateway forwards it as is. Some models read it; others return <code>200</code> and ignore it. Use this endpoint&#39;s own format.</p>
<h2 data-md="h2" id="prompt-caching" class="group">Prompt caching<a href="#prompt-caching" aria-label="Link to this section" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<p>Put <code>cache_control: {&quot;type&quot;: &quot;ephemeral&quot;}</code> on the <strong>last block</strong> of the stable prefix, or put <code>cache_control</code> at the top level of the body and it lands on the last cacheable block. For a 1-hour TTL use <code>{&quot;type&quot;: &quot;ephemeral&quot;, &quot;ttl&quot;: &quot;1h&quot;}</code>. Check <code>usage.cache_read_input_tokens</code> and <code>usage.cache_creation_input_tokens</code> to see whether it hit.</p>
<p>Caching matches the prefix in the order <code>tools</code> → <code>system</code> → <code>messages</code>; any byte that changes in the prefix invalidates everything after it. Keep stable content first and per-request values (timestamps, request ids) after the last <code>cache_control</code>.</p>
<p><code>cache_control</code> is not allowed on blocks inside <code>tool_result.content</code> — put it on the <code>tool_result</code> itself, or the request is rejected.</p>
