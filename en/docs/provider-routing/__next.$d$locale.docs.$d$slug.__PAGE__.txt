<h2 data-md="h2" id="one-model-id-a-pool-behind-it" class="group">One model id, a pool behind it<a href="#one-model-id-a-pool-behind-it" aria-label="Link to this section" class="ml-2 text-sand opacity-0 group-hover:opacity-100 focus-visible:opacity-100 touch:opacity-60">#</a></h2>
<p>The provider set for each model — and its order — is configured on the platform side, not per request. Your client only ever names the model (from <a href="/docs/models/">GET /v1/models</a>); which provider actually serves it is handled for you and can change between requests without any code change on your side.</p>
