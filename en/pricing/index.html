How pricing works

Top up once, pay per request.

Every model has its own price. Text is priced per token, images per image, video per second, and speech per 1,000 characters.

Top up credits

02project · allowlist

Scope a project key

Enable models on the project first. The key can only spend what that project allows.

03per-request

Pay when a request succeeds

Each model has its own price. Every charge shows its project, key, and model.

FAQ

Billing questions, answered.

FAQ

9
Is there a monthly fee?
No. You pay only for the tokens, images, seconds of video, or characters you actually use.
Do credits expire?
Never for pay-as-you-go credits.
Minimum top-up?
USD 5 to start calling models. Account signup itself is free.
Is signup free if top-up is USD 5?
Signup is free. The USD 5 is the minimum credit top-up before live API calls.
How does 1 USD = 100 credits work?
Prices are in USD, and $1 = 100 credits. A $0.15 request uses 15 credits from your project.
Where can I see every model's price?
In the price table on the Models page. Filter by type, vendor, or positioning, and sort any price column.
Am I charged when a request fails?
No. Credits are deducted only when a request succeeds.
What is the cache-read price?
Some text models charge less for input served from the prompt cache. Where a model has one, it's listed in the Cache read column.
Can I lock in a contract?
Optional for enterprise. Default is no lock-in.
