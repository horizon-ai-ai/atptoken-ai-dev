Text-to-image (Nano Banana 2 / gemini-3.1-flash-image) — complex prompts and final-quality renders; every tier is priced separately. Billed per delivered image at the tier of its longest side (≤1024 px = 1K, ≤2048 px = 2K, larger = 4K) — a model's default output can land in a higher tier than its pixel count suggests, and some models ignore the requested size. Passthrough of the model's official list price — no ATP markup. Failed generations are not billed. Preview: rates may change before general availability.

Where it fits

Good fit
  • Marketing mockups, posters, and ads that need legible, localized in-image text
  • Banners, vertical social posts, and wide backdrops using extreme aspect ratios up to 4K
  • Infographics and diagrams generated from notes or data
  • Complex, multi-part prompts that must be rendered as written
Usually not ideal
  • Work where maximum factual accuracy matters most — Google points to Nano Banana Pro (nano-banana-pro on ATP)
  • Editing or restyling an existing image — use nano-banana-2-edit, which takes reference images

FAQ

3
What can I send Nano Banana 2, and what do I get back?
Nano Banana 2 is a Google text-to-image model. Send a text prompt and you get back images at 1K / 2K / 4K.
How is Nano Banana 2 priced?
You pay per image. The price depends on the output size (1K / 2K / 4K). You only pay when a request succeeds. $1 = 100 credits. See pricing
How do I call Nano Banana 2 on ATP?
Create a project API key. Check that "nano-banana-2" shows up with GET https://api.atptoken.ai/v1/models, then follow the image generation docs with model set to that id.
