FAQ

4
Can Qwen 3.6 Max use tools, read images, or think before answering?
Tool calling: yes. Vision input: no. Extended thinking: no. Audio: no. These come from the ATP model catalog, so check with your key before you rely on one.
How is Qwen 3.6 Max priced?
You pay per 1M input tokens and per 1M output tokens. You only pay when a request succeeds. $1 = 100 credits. See pricing
Is there a newer Qwen (Alibaba) model than Qwen 3.6 Max on ATP?
Yes. Qwen 3.8 Max (qwen-3-8-max) came out on Aug 2, 2026, after Qwen 3.6 Max (Apr 20, 2026), and is the newer Qwen (Alibaba) text option on ATP. Both stay available: compare family prices on this page, then turn on the id you want for your project.
How do I call Qwen 3.6 Max on ATP?
Create a project API key and point any OpenAI-compatible SDK at https://api.atptoken.ai/v1. Set model to "qwen-3-6-max" (the API id, not the display name). Make sure the model is turned on for your project.
