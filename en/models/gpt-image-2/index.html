gpt-image-2 is OpenAI's GPT Image 2 model for generating and editing images, released to the API on April 21, 2026. OpenAI's prompting guide recommends it for text-heavy images, photorealism, and compositing, and it accepts custom sizes up to 3840×2160 (4K). On ATP it is a text-to-image preview billed on tokens.

FAQ

3
What does GPT Image 2 produce?
GPT Image 2 is an OpenAI image generation model. It returns images. The image generation docs list the inputs it accepts.
How is GPT Image 2 priced?
You pay per 1M text-input tokens and per 1M image-output tokens. You only pay when a request succeeds. $1 = 100 credits. See pricing
How do I call GPT Image 2 on ATP?
Create a project API key. Check that "gpt-image-2" shows up with GET https://api.atptoken.ai/v1/models, then follow the image generation docs with model set to that id.
