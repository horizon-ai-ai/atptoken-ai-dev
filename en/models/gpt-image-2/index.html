FAQ

How much does GPT Image 2 cost on ATP Token?
List rates for GPT Image 2 (API id gpt-image-2): text input $5.00 / image output $30.00 per 1M tokens. Billing uses credits (1 USD = 100 credits), debited from the project balance per completed request. There is no monthly platform fee; see Pricing for the minimum top-up.
How do I call GPT Image 2 via API?
Create a project API key, enable the API id gpt-image-2 (not the display name) on that project’s allowlist, point an OpenAI-compatible SDK at https://api.atptoken.ai/v1, and set model to "gpt-image-2". See the Quickstart on this page and the docs.
What are the context and capabilities of GPT Image 2?
Capability flags (thinking, tools, vision) follow the gateway model catalog — treat the catalog visible to your key as operational truth. Context is shown only when we have a reliable source. Vendor: OpenAI.
Who can use GPT Image 2 on ATP?
Only models on a project’s allowlist can be called with that project’s key (match the API id). Organization → workspace → project governance, per-request logs, and credit budgets are managed in the ATP Console.
