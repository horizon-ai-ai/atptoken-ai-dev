FAQ

How much does Nano Banana (Edit) cost on ATP Token?
List rates for Nano Banana (Edit) (API id nano-banana-edit): 1K $0.039 · 2K $0.039 · 4K $0.039 per image. Billing uses credits (1 USD = 100 credits), debited from the project balance per completed request. There is no monthly platform fee; see Pricing for the minimum top-up.
How do I call Nano Banana (Edit) via API?
Create a project API key, enable the API id nano-banana-edit (not the display name) on that project’s allowlist, point an OpenAI-compatible SDK at https://api.atptoken.ai/v1, and set model to "nano-banana-edit". See the Quickstart on this page and the docs.
What are the context and capabilities of Nano Banana (Edit)?
Capability flags (thinking, tools, vision) follow the gateway model catalog — treat the catalog visible to your key as operational truth. Context is shown only when we have a reliable source. Vendor: Google.
Who can use Nano Banana (Edit) on ATP?
Only models on a project’s allowlist can be called with that project’s key (match the API id). Organization → workspace → project governance, per-request logs, and credit budgets are managed in the ATP Console.
