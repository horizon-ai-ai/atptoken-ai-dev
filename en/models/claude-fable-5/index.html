FAQ

How much does Claude Fable 5 cost on ATP Token?
List rates for Claude Fable 5 (API id claude-fable-5): input $10.00 / output $50.00 per 1M tokens. Billing uses credits (1 USD = 100 credits), debited from the project balance per completed request. There is no monthly platform fee; see Pricing for the minimum top-up.
How do I call Claude Fable 5 via API?
Create a project API key, enable the API id claude-fable-5 (not the display name) on that project’s allowlist, point an OpenAI-compatible SDK at https://api.atptoken.ai/v1, and set model to "claude-fable-5". See the Quickstart on this page and the docs.
What are the context and capabilities of Claude Fable 5?
Capability flags (thinking, tools, vision) follow the gateway model catalog — treat the catalog visible to your key as operational truth. Context is shown only when we have a reliable source. Vendor: Anthropic.
Who can use Claude Fable 5 on ATP?
Only models on a project’s allowlist can be called with that project’s key (match the API id). Organization → workspace → project governance, per-request logs, and credit budgets are managed in the ATP Console.
