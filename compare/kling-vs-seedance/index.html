    03 / Fit

    When to pick which

    Where each family tends to fit, based on what the vendors document. Facts beyond our prices are cited under Sources.

    Pick Kling for

    • Lower per-second cost at 720P and 1080P at ATP's current prices — compare the rate table below.
    • Multi-shot story sequences from a single prompt: Kuaishou's 3.0 launch highlights 2–6 connected shots per call and single shots up to 15 seconds.
    • Editing existing footage: the O3 line on ATP includes video-to-video and natural-language video-edit variants, plus reference modes with up to seven images.
    • Silent clips: Kling audio generation is not yet available on ATP, so pick Kling when sound is added in post.
    All Kling models

    Pick Seedance for

    • Clips that should ship with generated audio — Seedance 2.0 supports optional generated audio on ATP.
    • Heavily conditioned generation: ByteDance's technical report describes up to 12 text, image, video and audio assets per generation, with first/last-frame control.
    • A wider resolution ladder in one model: seedance-2-0 renders 480p through 4k on ATP, so drafts and finals use the same id.
    • Fast iteration before a final render: seedance-2-0-fast trades resolution ceiling (720p) for a lower per-second rate.
    All Seedance models
    04 / Governance

    Use both under one key

    You rarely have to choose just one. On ATP both families sit behind one endpoint and one project key — so you can route each task to the model that fits and still keep one budget, one allowlist and one log.

    • One project key — spend and revocation bound to one project
    • Model allowlist — only the ids you enable can be called; others return 403
    • Project budget — credits are allocated down org → workspace → project, so the allocation is the cap
    • Per-request logs and one bill — model, key, project and credits for every call, across both vendors
    two_models.py · requests
    import requests

URL = "https://api.atptoken.ai/omni/media/v1/contents/generations/tasks"
H = {"Authorization": "Bearer atp-•••"} # one project key

for model in ["kling-v3-standard", "seedance-2-0-fast"]:
    task = requests.post(URL, headers=H, json={
        "model": model, "resolution": "720p", "duration": 5,
        "content": [{"type": "text", "text": "a red fox running through snow"}],
    }).json()
    print(model, task["id"]) # 202 → poll the task until it succeeds
    05 / FAQ

    Questions teams ask

    FAQ

    5
    Which is cheaper per second, Kling or Seedance?
    At ATP prices, Kling runs from $0.084/s (720P) (kling-v3-standard) to $0.168/s (1080P) (kling-o3-pro-video-edit); Seedance runs from $0.0538/s (480p) (seedance-2-0-fast) to $0.7776/s (4k) (seedance-2-0). Compare the same resolution: the rate table on this page lines them up by tier.
    Were the sample clips generated with identical settings?
    The prompt is identical, word for word. Resolution and duration are not: each model ran at its own ceiling, so one clip may be 1080p / 8s and another 720p / 10s. Every card states what that model actually produced, measured from the file.
    Do Kling and Seedance generate audio?
    On ATP, Seedance 2.0 supports optional generated audio. Kling audio generation is not yet available on ATP, so Kling clips come back silent. The sample clips on this page are silent.
    Can I use Kling and Seedance with one API key?
    Yes. On ATP both families use the same asynchronous video endpoint (POST /omni/media/v1/contents/generations/tasks) with the same atp- project key; you switch by changing the model field. Video models are enabled per project after an allowlist review — contact sales to turn them on.
    How do I keep a team on the models we approved?
    Use the project's model allowlist: enable only the model ids you approved, and calls to any other id are refused with 403. Give the project its own credit allocation so the budget is the ceiling, and review spend per model in the per-request logs.
