How teams use OpenAI on ATP

The same OpenAI models, with the controls a company needs around them: who can call which model, from which project, within what budget, and a record of every request.

  • Project API keys

    Every key belongs to one project and inherits its models and balance. Revoke one at any time without touching the rest.

  • Model allowlist per project

    Enable only the OpenAI models a project needs. Anything off the list can't be called with that project's keys.

  • Budgets

    Credits flow from organization to workspace to project. The allocation is the cap, so one team can't spend another team's budget.

  • Per-request logs

    Each call is recorded with its project, key, model, usage and credits debited, so spend is attributable down to a single request.

  • One wallet, one bill

    OpenAI and the other 10 providers on ATP draw from the same prepaid credits. No separate vendor contracts or invoices.

quickstart.py · OpenAI SDK
from openai import OpenAI

client = OpenAI(
  base_url="https://api.atptoken.ai/v1",
  api_key="atp-•••",
)

r = client.chat.completions.create(
  model="gpt-5.6-luna",
  messages=[{"role": "user", "content": "hi"}],
)
print(r.choices[0].message.content)

Point an existing SDK or HTTP client at ATP and set the model id. Confirm what your key can call with GET /v1/models. Full guide in the docs

FAQ

OpenAI API on ATP: FAQ

FAQ

6
How do I call the OpenAI API through ATP Token?
Create a project API key, enable the OpenAI model ids you need on that project's model allowlist, point an OpenAI-compatible SDK at https://api.atptoken.ai/v1 and set model to the API id (for example gpt-5.6-luna).
How much does the OpenAI API cost on ATP Token?
Prices for the 9 OpenAI models on ATP Token: input $0.022–$30.00 and output $6.00–$180.00 per 1M tokens. Usage is billed in credits (1 USD = 100 credits), debited from the project balance per completed request; failed requests are not billed. No monthly fee, USD 5 minimum top-up.
Which OpenAI model is cheapest on ATP Token?
By price (compared within each modality): Text: GPT-5.6 Luna (gpt-5.6-luna) at $1.00 input / $6.00 output per 1M tokens; Embedding: text-embedding-3-small (text-embedding-3-small) at $0.022 input per 1M tokens; Image: GPT Image 2 (gpt-image-2) at $5.00 input / $30.00 output per 1M tokens.
What are the newest OpenAI models on ATP Token?
The most recent OpenAI release we list is GPT-5.6 Sol (gpt-5.6-sol), GPT-5.6 Terra (gpt-5.6-terra), GPT-5.6 Luna (gpt-5.6-luna), released by OpenAI on Jul 9, 2026. The authoritative list is what GET /v1/models returns for your key.
Do OpenAI models support tool calling and vision?
Per the capability flags in the ATP model catalog: of 6 text models, 6 support tool calling, 6 accept image (vision) input and 6 support extended thinking. Each model's flags are in the table above.
How do teams control who can use OpenAI models, and how much they spend?
Each project has its own API keys and model allowlist — a OpenAI model that isn't on the list can't be called with that project's key. Credits flow from organization to workspace to project with budget caps, every request is logged with project, key, model and credits debited, and all providers share one wallet and one bill.
