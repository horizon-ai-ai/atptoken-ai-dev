<h2 id="three-ai-pricing-models-finance-will-meet">Three AI pricing models finance will meet</h2>
<p>As of October 2026, the <a href="https://claude.com/pricing" target="_blank" rel="noopener noreferrer">Claude pricing page</a> shows all three models from a single vendor:</p>
<ul>
<li>Per seat: Claude Team standard seats are $25 per seat per month billed monthly, or $20 billed annually. Premium seats are $125 monthly or $100 annually.</li>
<li>Seat plus usage: Claude Enterprise lists &quot;Seat price + usage at API rates&quot;, at $20 per seat per month billed annually, with usage cost that scales with model and task.</li>
<li>Token-based: API access charged per token. Claude Sonnet 4.6 is $3 per 1M input tokens and $15 per 1M output tokens (<a href="https://platform.claude.com/docs/en/about-claude/pricing" target="_blank" rel="noopener noreferrer">Anthropic pricing</a>), the same as the ATP list rate for <a href="/models/claude-sonnet-4-6/">claude-sonnet-4-6</a>.</li>
</ul>
<p>Most companies end up with a mix: seats for people who chat with a model all day, and token billing for the applications, automations and agents that call models from code.</p>
<h2 id="worked-comparison-a-40-person-team">Worked comparison: a 40-person team</h2>
<p>Assumptions for one month with 21 working days, all requests on claude-sonnet-4-6 at $3 / $15:</p>
<ul>
<li>A standard request is 3,000 input and 600 output tokens: 3,000 × $3 ÷ 1M + 600 × $15 ÷ 1M = $0.009 + $0.009 = $0.018.</li>
<li>A long-document request is 20,000 input and 600 output tokens: $0.06 + $0.009 = $0.069.</li>
</ul>

<p>The same 40 people on Claude Team standard seats cost 40 × $25 = $1,000 a month on monthly billing, or 40 × $20 = $800 on annual billing.</p>
<p>Three things finance should take from this table:</p>
<ol>
<li>Break-even is per person. At $0.018 per request, a user matches a $25 seat at $25 ÷ $0.018 = 1,389 requests a month, about 66 per working day. At $0.069 per request it is about 362 a month, or 17 per working day.</li>
<li>The heavy group costs $57.96 per person on tokens, more than twice a $25 seat. The light group costs under $1 per person.</li>
<li>The comparison prices model usage only. A seat includes the vendor&#39;s chat apps and features; token usage needs an internal tool or integration to call the API, which has its own cost.</li>
</ol>
<p>Agentic work changes the scale. Anthropic reports Claude Code averages around $13 per developer per active day and $150 to $250 per developer per month (<a href="https://code.claude.com/docs/en/costs" target="_blank" rel="noopener noreferrer">Claude Code costs</a>), several times the chat usage above. Budget coding agents as their own line.</p>
<h2 id="a-chargeback-model-with-credits-per-project">A chargeback model with credits per project</h2>
<p>Seat chargeback is simple: seats × price per department. Token chargeback needs one more step, because spend lands on workloads rather than on people. The model that holds up at month-end close:</p>
<ul>
<li>Each workload is a project with its own key, grouped into a workspace per department.</li>
<li>Finance funds the organization, and each project gets a monthly allocation in credits (1 credit = USD 0.01).</li>
<li>Each cost center is charged for credits consumed, not credits allocated.</li>
</ul>

<h2 id="what-makes-a-token-budget-miss">What makes a token budget miss</h2>
<ul>
<li>A model switch. Moving proposal-drafts from gpt-5.5 to claude-sonnet-4-6 changes its cost per request from $0.075 to $0.0405, with no change in volume. Check the <a href="/models/compare/">model compare pages</a> before and after.</li>
<li>Context growth. If support-bot prompts grow from 1,284 to 4,000 input tokens, cost per reply rises from $0.010032 to $0.01818.</li>
<li>Reasoning tokens. OpenAI and Anthropic bill reasoning tokens as output, so turning on extended thinking can multiply output cost without a visible change in answers.</li>
<li>Agents. Each step resends context; Anthropic reports agent teams use approximately 7× more tokens than standard sessions in plan mode.</li>
</ul>
<p>A weekly look at consumed against allocated catches all four before month-end. The detail on reading the numbers is in <a href="/blog/how-to-read-your-ai-bill/">LLM token cost: how to calculate it</a>.</p>
<h2 id="setting-this-up-in-atp-token">Setting this up in ATP Token</h2>
<ol>
<li>Create a Team organization with one workspace per department and one project per workload (<a href="/docs/console-setup/" class="doc-term-def" data-def="The top level of an account. Workspaces and projects sit underneath it.">console setup</a>).</li>
<li>Top up through the Billing page (minimum USD 5; packages of USD 5, 50, 200 and 1,000) and allocate credits from the organization to workspaces and projects (<a href="/docs/topup/" class="doc-term-def" data-def="Adding credits to the wallet. Minimum 5 USD, pay as you go.">top up &amp; wallet</a>). Top-ups are non-refundable.</li>
<li>Set each project&#39;s allowed models and create its <code>atp-</code> key, so spend by key equals spend by project.</li>
<li>Each week, compare Allocated and Consumed in the allocation tree on the Usage page (<a href="/docs/spend/">tracking spend</a>).</li>
<li>At month-end, close from billing events and charge each cost center for consumed credits (<a href="/docs/credits/" class="doc-term-def" data-def="The billing unit. 1 USD = 100 credits; usage converts at each model's list rate.">how credits work</a>).</li>
</ol>
